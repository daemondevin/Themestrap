A fully self-contained Themestrap scrollbar. No vendor JS dependencies — wheel, pointer, touch, and keyboard all built in from scratch.

options

Feature Options

Six of the most-used configuration options demonstrated live, each on its own independently-configured panel.

Auto-Hide autoHideScrollbar: true

Hover over the panel — the scrollbar fades in. It fades out 400 ms after you stop scrolling.

Hover here. The scrollbar fades in on activity via a CSS transition: opacity 0.2s ease-in-out and fades out after the idle delay.

JS handles both scroll activity and hover state so the auto-hide works correctly alongside the CSS cascade.

Mouse, touch, and keyboard input all trigger the show state independently of one another.

Setting alwaysShowScrollbar: 1 alongside autoHideScrollbar: true — alwaysShowScrollbar wins.

Scroll Buttons scrollButtons.enable: true

Arrow buttons on the track scroll by scrollAmount px per click. Hold for continuous scrolling.

Click the ▲ ▼ arrows on the track to scroll 35 px at a time. Hold for continuous firing.

Arrows are drawn with pure CSS borders — no sprite sheet or image file is required. Dark-theme arrow colour is detected automatically via the [class*="dark"] selector.

Rail-click page-jumps (clicking the track above or below the thumb) are active at the same time as button scrolling.

Configure the step size with scrollButtons.scrollAmount in pixels.

Always Visible alwaysShowScrollbar: 1

The track and thumb stay visible even when content fits entirely in the viewport — useful for fixed sidebars.

alwaysShowScrollbar: 1 keeps both track and thumb permanently visible regardless of overflow state.

Use alwaysShowScrollbar: 2 to keep the track but hide the thumb when content doesn't overflow — a visual affordance without implying scrollability.

Snap Scrolling snapAmount: 60

Every scroll action rounds to the nearest 60 px boundary. The panel snaps cleanly between each row.

01 Snap grid boundary — 0 px
02 Snap grid boundary — 60 px
03 Snap grid boundary — 120 px
04 Snap grid boundary — 180 px
05 Snap grid boundary — 240 px
06 Snap grid boundary — 300 px
Instant Jump scrollInertia: 0

Setting scrollInertia to 0 disables easing entirely — scroll position changes snap immediately with no animation.

Each wheel notch, keypress, or dragger drag maps directly to the final position with zero animation latency. Useful inside canvas dashboards or code editors where the easing feels like lag.

Touch momentum still applies a 200 ms minimum animation for flick gestures, since the momentum physics are separate from the config duration.

Track-click page-jumps also jump instantly rather than easing into place.

Outside Position scrollbarPosition: 'outside'

The track renders outside the element, leaving the full content width. Parent must allow overflow: visible.

In outside mode the track sits outside the element's bounds, so the content area loses no width. The plugin sets overflow: visible on the element automatically.

Ideal for bordered panels where an interior scrollbar would overlap the border or trim the content column.

Make sure the wrapping layout has enough clearance — the track is 16 px wide and positioned 26 px from the element's right edge when in outside mode.

callbacks

Lifecycle Callbacks

Five hooks fire at key scroll events. Each receives a data object: { scrollY, scrollX, maxScrollY, maxScrollX, pctY, pctX }.

Live Log

Scroll the panel below to see callbacks fire in real time.

Scroll this panel — watch the log update. whileScrolling fires every animation frame; onScroll fires once when it settles.

onTotalScroll fires at the very bottom. onTotalScrollBack fires when you return to the top. Both support an offset in pixels.

All five callbacks receive the same data object so you can build a progress bar, lazy-loader, or sticky header using any single callback.

Callbacks are set programmatically on init — they are not supported through data-plugin-options.

// scroll the panel above ↑
Configuration Example 
// Programmatic init — callbacks go in the config object:
$('#myPanel').themestrapPluginScrollbar({
  theme: 'dark',
  scrollInertia: 700,
  callbacks: {
 
    // Fires once when scroll animation begins
    onScrollStart: function(data) {
      console.log('start — at', data.pctY + '%');
    },
 
    // Fires every rAF frame — use sparingly
    whileScrolling: function(data) {
      $('#progress').css('width', data.pctY + '%');
    },
 
    // Fires once when the animation settles
    onScroll: function(data) {
      console.log('settled at', data.scrollY + 'px');
    },
 
    // Fires when scroll reaches (or passes) the bottom
    onTotalScroll: function() {
      loadNextPage(); // infinite scroll hook
    },
 
    // How many px from the bottom counts as "at bottom"
    onTotalScrollOffset: 80,
 
    // Fires when scroll returns to (or passes) the top
    onTotalScrollBack: function() {
      showBackToTop(false);
    },
 
    onTotalScrollBackOffset: 0,
  }
});
