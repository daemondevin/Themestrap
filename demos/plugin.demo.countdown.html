Countdown plugin

DaisyUI-style CSS slot-machine countdown — zero dependencies, pure CSS animation

Labels Under Boxes Clock Labels Side API Control Event Hook
01

Labels Under — default layout

<div
  data-plugin-countdown
  data-plugin-countdown-date="2027-01-01T00:00:00"
  data-plugin-options='{"layout":"labels-under","fontSize":"font-mono"}'
  style="font-size:3.5rem"
></div>
// waiting for tick…
02

Boxes — pill background per unit

<div
  data-plugin-countdown
  data-plugin-countdown-date="2027-01-01T00:00:00"
  data-plugin-options='{"layout":"boxes","boxBg":"#e8672a","boxColor":"#fff","boxRadius":"8px"}'

05

Programmatic API — pause / resume / setDate

// manual init
$('#demo-api').themestrapPluginCountdown({
  layout: 'labels-under',
  date:   new Date(Date.now() + 90000)  // 90 seconds from now
});

const inst = $('#demo-api').data('__pluginCountdown');

inst.pause();
inst.resume();
inst.setDate(new Date(Date.now() + 86400000));
inst.destroy();
// click a button to see API output here
06

Finished Event — ts.countdown.finished

Counting down 10 seconds… 

$('#demo-event').on('ts.countdown.finished', function() {
  console.log('Countdown finished!');
});

$('#demo-event').themestrapPluginCountdown({
  layout:      'clock',
  separator:   ':',
  showDays:    false,
  showHours:   false,
  date:        new Date(Date.now() + 10000)
});
// ts.countdown.finished fires when timer hits 0
