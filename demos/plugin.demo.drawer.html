PluginDrawer

A panel that slides in from any edge of the screen. It brings its own backdrop, locks page scroll, traps focus, closes on Escape, and can be dragged away by its handle. Built for mobile sheets, side navigation and filter panels.

bottom · top · left · right drag to dismiss focus trap scroll lock --ts-drw-* tokens
01 Four Directions direction

Each button opens a drawer through data-drawer-open="id". Bottom and top drawers get a drag handle automatically. Side drawers have none, so they close with the backdrop, the close button or Escape. 

<!-- Trigger, anywhere on the page -->
<button data-drawer-open="share-sheet">Share</button>

<!-- Drawer root -->
<div data-plugin-drawer id="share-sheet"
     data-plugin-options='{"direction": "bottom"}'>
    <div data-drawer-backdrop></div>
    <div data-drawer-panel>
        <h2 data-drawer-title>Share this page</h2>
        <p data-drawer-description>Send a link or copy it.</p>
        ...
        <button data-drawer-close>Cancel</button>
    </div>
</div>

<!-- Side drawers only change the direction -->
<div data-plugin-drawer id="side-nav"
     data-plugin-options='{"direction": "left"}'> ... </div>
02 Drag to Dismiss & Long Content dragThreshold · velocityThreshold

Grab the handle and pull down. Let go past a quarter of the panel's height, or flick it quickly, and it closes. Anything less snaps back. The handle stays pinned while the content scrolls, and dragging only ever starts from the handle, so scrolling the list never closes the sheet by accident. 

<div data-plugin-drawer id="release-notes"
     data-plugin-options='{"dragThreshold": 0.25, "velocityThreshold": 0.6}'>
    <div data-drawer-panel>
        <!-- The handle is injected here, as the first child -->
        <h2 data-drawer-title>What's new</h2>
        ...
    </div>
</div>
03 Requires a Choice closeOnBackdrop · closeOnEscape · draggable

Turn off the backdrop click, Escape and the handle, and the only way out is a button inside the panel. Use this when the reader must decide before carrying on. 

<div data-plugin-drawer id="terms"
     data-plugin-options='{
        "closeOnBackdrop": false,
        "closeOnEscape":   false,
        "showHandle":      false,
        "draggable":       false
     }'>
    ...
</div>
04 Theming & Dark Mode --ts-drw-* · data-bs-theme

Every color, radius, size and timing comes from a --ts-drw-* token. Set them on :root for every drawer, or on one drawer's root for just that one. Dark mode follows the same three tiers as PluginDarkMode, so data-bs-theme="dark" on a drawer, or on <html>, is enough. 

/* One branded drawer */
#upgrade-sheet {
    --ts-drw-bg:           #0e2238;
    --ts-drw-overlay:      rgba(4, 10, 20, .72);
    --ts-drw-radius:       1.5rem;
    --ts-drw-handle:       rgba(32, 226, 215, .55);
    --ts-drw-handle-hover: #20e2d7;
    --ts-drw-side-w:       min(420px, 90vw);
}

/* The panel inherits the page's text color, so set one to match */
#upgrade-sheet [data-drawer-panel] { color: #e2eaf4; }
05 JavaScript API open · close · toggle · destroy · events

This drawer has the .manual class, so the page initializes it from the controls below. Change the options and press Apply to rebuild it. Every drawer on the page writes to the event log.

API
isOpen: false
Event log, every drawer on this page
Open a drawer and its events appear here…
// Manual init (the element carries .manual)
$('#api-drawer').themestrapPluginDrawer({
    direction: 'right',
    onOpen:  function ($el) { console.log('opening', $el.attr('id')); },
    onClose: function ($el) { console.log('closed',  $el.attr('id')); }
});

// Always read the instance from a fresh selection
const drw = $('#api-drawer').data('__pluginDrawer');

drw.open();
drw.close();
drw.toggle();
drw.close(); drw.open();   // open() during the close slides it straight back in
drw.isOpen;            // true while open; false as soon as a close starts

// jQuery events fire on the drawer root and bubble
$(document).on('drawer:open drawer:close', '[data-plugin-drawer]', function (e, instance) {
    console.log(e.type, this.id, instance.options.direction);
});

// Rebuild with new options (destroy() removes the handle it injected)
drw.destroy();
$('#api-drawer').themestrapPluginDrawer({ direction: 'left' });
