Themestrap · Plugin

Particles data-plugin-particlesjQuery only

A canvas particle background for heroes, sections and cards: drifting dots that twinkle, link into a network, react to the pointer and scatter on click. It pauses off screen and in hidden tabs, and holds still for visitors who ask for reduced motion. Replaces particles.js.

01

Default Field

data-plugin-particles

Drop the element inside any positioned container. Particles swell away near the pointer (hover.mode: "bubble") and scatter when you click (click.mode: "repulse"). Content stays clickable because the canvas ignores the pointer.

Hover and click

Particles fade under the pointer and scatter on click.


<section class="hero">   <!-- any positioned container -->
    <div data-plugin-particles
         data-plugin-options='{"density": 160, "color": "#0088cc"}'></div>
    <h1>Hover and click</h1>
</section>
02

Network and Grab

links · hover.mode: "grab"

links.enable joins particles that drift close together. In grab mode the pointer pulls lines from nearby particles.

Connected

Move the pointer through the field.


{
    "density": 70,
    "color": "#2ab8c8",
    "links": { "enable": true, "distance": 120, "opacity": 0.35 },
    "hover": { "mode": "grab", "distance": 160 },
    "click": { "mode": null }
}
03

Snowfall

direction · speed

A direction gives the field a steady drift. Pair it with white, large, low-opacity particles and no pointer effects for snow.

Let it snow

direction: "bottom"


$('#snow').themestrapPluginParticles({
    density: 120, color: '#ffffff', size: 4, opacity: 0.7,
    speed: 1.2, direction: 'bottom',
    twinkle: { enable: false }, hover: { mode: null }, click: { mode: null }
});
04

Push and Bounce

click.mode: "push" · outMode · color array

An array of colors is sampled at random. click.mode: "push" adds particles where you click (up to maxParticles, after which the oldest make room), and outMode: "bounce" keeps everything inside the box.

Click to add

Hover to push particles away.


{
    "count": 40,
    "color": ["#e8672a", "#2ab8c8", "#f5f0e8"],
    "size": 6,
    "outMode": "bounce",
    "hover": { "mode": "repulse", "distance": 120 },
    "click": { "mode": "push", "count": 6 }
}
05

API

pause · play · burst · setOptions · refresh

Control a field from your own code. setOptions() followed by refresh() rebuilds it with new settings. ts.particles.ready fires once the first frame is drawn.

Under control

Use the buttons below.


const fx = $('#hero-particles').data('__pluginParticles');
fx.pause();
fx.play();
fx.burst(200, 150, 12);
fx.setOptions({ color: '#e8672a', links: { enable: true } }).refresh();
