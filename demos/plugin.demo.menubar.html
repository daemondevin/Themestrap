Checkbox Items

data-menubar-type="checkbox"
Interface
HTML — Checkbox item
<!-- Toggle with data-menubar-checked="true" for initial on state -->
<button data-menubar-item
        data-menubar-type="checkbox"
        data-menubar-checked="true">
  <span data-menubar-indicator>✓</span>
  <span data-menubar-item-label>Show Status Bar</span>
</button>

// The plugin toggles aria-checked and .ts-mb-indicator-on automatically.
// Read current state from the element:
$('[data-menubar-item][data-menubar-type="checkbox"]').attr('aria-checked'); // "true"|"false"

Font Size
Alignment
HTML — Radio group
<!-- Wrap radio items in [data-menubar-radio-group] -->
<div data-menubar-radio-group>
  <button data-menubar-item
          data-menubar-type="radio"
          data-menubar-value="small">
    <span data-menubar-indicator>●</span>
    <span data-menubar-item-label>Small</span>
  </button>
  <!-- ... more radio items -->
</div>

// Read selected value from menubar:select event:
$('#my-menubar').on('menubar:select', function(e) {
  const { type, value, label } = e.detail.payload;
  if (type === 'radio') console.log('Selected:', value);
});

Nested Sub-menus

data-menubar-sub
HTML — Submenu
<!-- Wrap sub-trigger + sub-content inside [data-menubar-sub] -->
<div data-menubar-sub>

  <!-- This acts as both a menuitem and a sub-menu trigger -->
  <button data-menubar-item data-menubar-sub-trigger>
    <span data-menubar-item-label>Align Objects</span>
  </button>

  <div data-menubar-sub-content>
    <button data-menubar-item>Align Left</button>
    <button data-menubar-item>Align Center</button>
  </div>

</div>

// Keyboard: ArrowRight / Enter opens sub; ArrowLeft / Esc closes it.

Options & Keyboard Reference

Plugin options

OptionTypeDefaultDescription
subDelayNumber200ms before a hovered sub-menu trigger opens.
subCloseDelayNumber120ms hover-out grace period before sub-menu closes.
animationDurationNumber150Panel open/close animation duration in ms.
closeOnOutsideBooleantrueClose active menu on outside click.
closeOnEscapeBooleantrueClose active menu on Escape key.
loopBooleantrueArrow key navigation wraps between first and last menus.
onOpenFunctionnullCallback (menuIndex, instance) fired when a menu opens.
onCloseFunctionnullCallback (menuIndex, instance) fired when a menu closes.
onSelectFunctionnullCallback ($item, payload, instance) on item activation.

ContextKeyAction

Trigger focused↑Open menu, focus last item.
Menu open↑ ↓Navigate items.
Menu openHome / EndJump to first / last item.
Menu open→Move to next menu (not on sub-trigger).
Menu open←Move to previous menu (not inside sub).
Sub-trigger focused→ / EnterOpen sub-menu, focus first sub-item.
Sub-menu open← / EscClose sub-menu, return focus to trigger.
AnyEscClose menu, return focus to its trigger.
AnyLetterType-ahead: jump to matching item.
