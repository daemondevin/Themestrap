Themestrap · Plugin

Calendar data-plugin-calendar

A dependency-free Calendar component that supports single, multiple, and range selection with keyboard navigation, disabled date rules, and a roving tabindex ARIA grid.


Selection Modes
Basic Single Selection mode: 'single' 
<div data-plugin-calendar></div>

<script>
$('#cal-basic').themestrapPluginCalendar({
  mode: 'single',
  selected: '2026-08-26'
});
</script>
Select a date — the selected value is reported here.
Multiple Selection mode: 'multiple' 
$('#cal-multiple').themestrapPluginCalendar({
  mode: 'multiple',
  selected: ['2026-08-04', '2026-08-12', '2026-08-26'],
  onSelect(dates) {
    console.log(dates);
  }
});
Click dates to toggle them on and off.
Range Selection mode: 'range' 
$('#cal-range').themestrapPluginCalendar({
  mode: 'range',
  selected: {
    from: '2026-08-10',
    to:   '2026-08-18'
  },
  showFooter: true
});
Click a start date, then an end date. Hover previews the range.
Constraints
Week Start & Outside Days weekStartsOn · showOutsideDays
SUNDAY START
MONDAY START · NO OUTSIDE DAYS
// Sunday start, outside days visible
$('#cal-sunday').themestrapPluginCalendar({
  initialMonth: '2026-08-01',
  weekStartsOn: 0,
  showOutsideDays: true
});

// Monday start, outside days hidden
$('#cal-monday').themestrapPluginCalendar({
  initialMonth: '2026-08-01',
  weekStartsOn: 1,
  showOutsideDays: false
});
weekStartsOn accepts 0 (Sunday) or 1 (Monday).
Date Limits minDate · maxDate 
$('#cal-limits').themestrapPluginCalendar({
  initialMonth: '2026-08-01',
  minDate: '2026-08-05',
  maxDate: '2026-08-25',
  showFooter: true
});
Only dates from August 5 through August 25 are selectable.
Disabled Dates array + function
DISABLED ARRAY
DISABLED FUNCTION
// Specific dates
$('#cal-disabled-array').themestrapPluginCalendar({
  initialMonth: '2026-08-01',
  disabled: ['2026-08-03', '2026-08-11', '2026-08-19', '2026-08-27']
});

// Predicate function
$('#cal-disabled-fn').themestrapPluginCalendar({
  initialMonth: '2026-08-01',
  disabled: date => date.getDay() === 0 || date.getDay() === 6
});
Disabled dates accept an array of dates or a date => boolean predicate.
Display Options
Fixed Six-Week Grid & Today Footer fixedWeeks · showFooter 
$('#cal-footer').themestrapPluginCalendar({
  initialMonth: '2026-08-01',
  fixedWeeks: true,
  showOutsideDays: true,

Exactly six calendar rows are rendered; Today returns to the current month.
Keyboard Navigation & Accessibility Arrow · PageUp/Down · Home · End

Keyboard controls

← →   previous / next day
↑ ↓   previous / next week
PageUp / PageDown   previous / next month
Home / End   first / last day of month
Focus a day button, then use the keys above. The plugin maintains a roving tabindex.
// Day buttons expose keyboard-friendly grid semantics.
// Arrow keys move by day/week; PageUp/PageDown changes month;
// Home/End moves to the first/last day of the current month.
Calendar cells use role="grid" and a roving tabindex.

const cal = $('#cal-api').data('__pluginCalendar');

cal.getValue();                    // current selection

cal.goToMonth(2026, 8);             // month is 0-indexed
cal.goToToday();                    // current month
cal.destroy();                      // teardown

$('#cal-api').themestrapPluginCalendar({
