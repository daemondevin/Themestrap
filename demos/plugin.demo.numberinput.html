A stepper for number fields: minus and plus buttons that match your other inputs, hold-to-repeat, keyboard control, bounds and a unit label. The real input stays in the page, so forms and validation keep working.

01

Default Stepper

data-plugin-numberinput

Reads min, max and step from the input. Click the buttons, hold one to repeat, or use the keyboard: ↑ ↓ one step, Shift with them (or PgUp PgDn) ten, Home End the limits. Type a number outside the range and leave the field: it is clamped.


<input type="number" name="per_page" value="8" min="1" max="50" data-plugin-numberinput>

02

Unit Label and Sizes

unit · size · block

A unit sits inside the field after the value. Three heights match your other inputs, and block fills the width of the parent.






$('#width').themestrapPluginNumberInput({ unit: 'px' });
$('#small').themestrapPluginNumberInput({ size: 'sm' });
$('#large').themestrapPluginNumberInput({ size: 'lg', block: true });
03

Stacked Layout and Decimals

layout · step · precision

The stacked layout puts small arrows at the right, as in a compact form. A step of 0.1 shows one decimal, and the arithmetic never produces values like 0.30000000000000004. The mouse wheel works while the field is focused.


$('#opacity').themestrapPluginNumberInput({ layout: 'stacked', wheel: true });
04

API and Events

getValue · setValue · increment

Drive the field from your own code. The input fires ordinary input and change events, plus ts.numberinput.change with the source of the change.


const ni = $('#qty').data('__pluginNumberInput');
ni.setValue(10);          // clamps to min and max
ni.increment(5);
ni.setMax(12);
document.getElementById('qty').addEventListener('ts.numberinput.change', function (e) {
    console.log(e.detail.value, e.detail.source);   // 12, "button"
});

Theming

--ts-ni-*

Colors are custom properties with light, dark and explicit-light tiers. Set them on the field or on :root to restyle every instance.


.warm {
    --ts-ni-border-focus: #e8672a;
    --ts-ni-radius:       999px;
    --ts-ni-btn-hover:    rgba(232, 103, 42, .25);
    --ts-ni-focus-ring:   0 0 0 3px rgba(232, 103, 42, .25);
}
