02

Bar Markup

data-plugin-gdpr

Place the bar element anywhere in <body> — the plugin positions it fixed to the bottom edge.

🍪 We use cookies to improve your experience. 
<!-- Bar: place once in <body> -->
<div data-plugin-gdpr
     data-plugin-options='{"cookieBarShowDelay": 3000, "expires": 365}'>

  <p>🍪 We use cookies to improve your experience.</p>

  <div class="d-flex gap-2">
    <button class="gdpr-agree-trigger btn btn-sm btn-primary">Accept All</button>
    <button class="gdpr-preferences-trigger btn btn-sm btn-outline-light">Preferences</button>
  </div>

</div>

<!-- Re-open popup from a footer link -->
<a href="#" class="gdpr-open-preferences">Manage Cookies</a>
03

Preferences Popup Markup

.gdpr-preferences-popup

One popup per page. Place it outside any transform or overflow:hidden container so the fixed overlay renders correctly.

<!-- Popup: place once, near the end of <body> -->
<div class="gdpr-preferences-popup">
  <div class="gdpr-preferences-popup-content">
    <h5>Cookie Preferences</h5>

    <form class="gdpr-preferences-form">
      <!-- Hidden inputs are always included -->
      <input type="hidden" class="gdpr-input" value="necessary" />

      <div class="form-check">
        <input class="form-check-input gdpr-input"
               type="checkbox" value="analytics" />
        <label class="form-check-label">Analytics</label>
      </div>

      <div class="form-check">
        <input class="form-check-input gdpr-input"
               type="checkbox" value="marketing" />
        <label class="form-check-label">Marketing</label>
      </div>

      <button type="submit" class="btn btn-primary mt-3">SAVE PREFERENCES</button>
    </form>

    <button class="gdpr-close-popup btn btn-link btn-sm mt-2">Close</button>
  </div>
</div>
04

Consent-Gated Content

PluginGDPRWrapper

Two wrappers — each guards content behind a different consent category. Save preferences above to see them update live.

checkCookie: "analytics"

🔒 Analytics Content Accept analytics cookies to reveal this block.

checkCookie: "marketing"

🔒 Marketing Content Accept marketing cookies to reveal this block. 
<!-- Show existing DOM content only when 'analytics' consent is present -->
<div data-plugin-gdpr-wrapper
     data-plugin-options='{"checkCookie": "analytics"}'>
  <p>Placeholder — shown until consent is granted.</p>
</div>

<!-- Replace content via AJAX once 'marketing' consent is present -->
<div data-plugin-gdpr-wrapper
     data-plugin-options='{"checkCookie":"marketing","ajaxURL":"/partials/ad.html","loadDelay":800}'>
</div>
// wrapper states update when preferences change
05

JavaScript API

public methods

Public methods available on the PluginGDPR instance and the ts.gdpr.consent window event:

// Retrieve the PluginGDPR instance
const gdpr = $('[data-plugin-gdpr]').data('__gdpr');

gdpr.removeCookieBar();   // transition bar out without writing a cookie
gdpr.clearCookies();     // remove themestrap-privacy-bar and themestrap-gdpr-preferences
gdpr.destroy();          // full teardown — unbind all .gdpr events, remove injected CSS

// Listen for consent changes on the window
window.addEventListener('ts.gdpr.consent', e => {
  console.log(e.detail.categories); // e.g. ['necessary', 'analytics']
});

// Retrieve the PluginGDPRWrapper instance
const wrapper = $('[data-plugin-gdpr-wrapper]').data('__gdprwrapper');
wrapper.destroy();  // empties wrapper content and removes instance data
// click a button above to test
