01

Default — exclusive, first item open

exclusive: true · openIndex: 0

Themestrap is a zero-build jQuery + Bootstrap 5 component library for MODX 3. Every plugin follows the same architectural pattern — IIFE wrapper, class lifecycle, lazy CSS injection, and a jQuery bridge — so the library is consistent and predictable.

Each panel animates between 0 px and its measured scrollHeight using a CSS transition on the clipping shell. After the transition ends the inline style is removed and a height: auto CSS rule takes over, so the panel can grow with its content without needing a re-measurement.

Yes. The plugin only scans direct children with [data-accordion-item] so a nested accordion does not bleed into the outer one. Each gets its own sequential UID for ARIA wiring.

↑ / ↓ move focus between triggers, Home / End jump to the first or last. Space and Enter activate the focused trigger (native on <button>, polyfilled on other elements).

<div id="my-faq">
  <div data-accordion-item>
    <button type="button" data-accordion-trigger>Question</button>
    <div data-accordion-panel><p>Answer.</p></div>
  </div>
  <!-- repeat… -->
</div>

$('#my-faq').themestrapPluginAccordion({
  exclusive:  true,   // one panel open at a time
  openIndex:  0,      // first item starts open
});
// ready

04

Programmatic API

open · close · toggle · openAll · closeAll · disable

Content for item A. Use the buttons below to control this accordion programmatically.

Content for item B. Each button calls a method on the retrieved instance.

Content for item C. openedIndexes() returns the array of currently open item indices.

const acc = $('#acc-api').data('__accordion');

acc.open(0);             // open item 0
acc.close(1);            // close item 1
acc.toggle(2);           // flip item 2
acc.openAll();           // no-op in exclusive mode beyond first
acc.closeAll();
acc.openedIndexes();     // → [0, 2]
acc.setDisabled(true);   // entire accordion inert
acc.refresh();           // re-scan after DOM mutations
acc.destroy();
// click a button above
05

Events

open · opened · close · closed · change · ready

Events fire in pairs: open.ts.accordion starts the animation, opened.ts.accordion fires after it completes.

close.ts.accordion starts the collapse, closed.ts.accordion fires once the panel is fully hidden.

$('#acc-events')
  .on('open.ts.accordion',   (e, idx) => log('open',   idx))
  .on('opened.ts.accordion', (e, idx) => log('opened', idx))
  .on('close.ts.accordion',  (e, idx) => log('close',  idx))
  .on('closed.ts.accordion', (e, idx) => log('closed', idx))
  .on('change.ts.accordion', (e, idx, isOpen) => log('change', idx, isOpen));
// interact with the accordion above
