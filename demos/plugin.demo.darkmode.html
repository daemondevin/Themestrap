DarkMode plugin

System-preference-aware light/dark toggle with localStorage persistence, Bootstrap data-bs-theme sync, and a static API

Toggle button Custom trigger Static API Events
01

Default — icon toggle button injected into the wrapper

auto-renders ☀/🌙 button

Live preview surface

This surface transitions between light and dark when you click the toggle. The plugin sets data-bs-theme on <html> and adds html.dark.

<div id="dm-wrapper"></div>

$('#dm-wrapper').themestrapPluginDarkMode({
  storageKey: 'theme',
  // Reads localStorage on init; falls back to prefers-color-scheme.
  // Sets data-bs-theme on <html> + adds html.dark on every change.
});
// click the sun/moon button above
02

Custom trigger — renderIcon: false, provide your own button

renderIcon: false

Custom button preview

Pass renderIcon: false and supply your own trigger. Call themestrap.DarkMode.toggle() from its click handler.

<button onclick="themestrap.DarkMode.toggle()">
  Toggle theme
</button>

$('#dm-holder').themestrapPluginDarkMode({
  renderIcon: false,
  onChange: (theme) => {
    myBtn.textContent = theme === 'dark' ? '🌙 Dark' : '☀️ Light';
  }
});
// click the button to toggle and watch the custom label update
03

Static API — themestrap.DarkMode.*

getTheme · setTheme · toggle · reset

Current theme: —

// Available as soon as the plugin is initialized once on the page.
themestrap.DarkMode.getTheme();            // → 'light' | 'dark'
themestrap.DarkMode.setTheme('dark');     // sets + persists
themestrap.DarkMode.toggle();              // flips current theme
themestrap.DarkMode.reset();              // clears localStorage, reverts to system pref
// click a button above
04

Events — change.ts.darkmode on the wrapper

$('#dm-wrapper')
  .on('change.ts.darkmode', (e, theme) => {
    console.log('Theme changed to:', theme); // 'light' | 'dark'
  });

// onChange callback (option alternative to the event):
$('#dm-wrapper').themestrapPluginDarkMode({
  onChange: (theme) => console.log(theme),
});
