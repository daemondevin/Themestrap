02

Rich Text Editor Toolbar

SVG icons · multiple toggle groups
Select text or place cursor, then use the toolbar above to apply formatting. Arrow keys navigate between toolbar items without leaving the editor flow. 
<!-- Multiple-type group: any combination can be active -->
<div data-toolbar-toggle-group data-toolbar-type="multiple">
  <button class="ts-tb-icon" data-toolbar-toggle-item data-toolbar-value="bold">...svg...</button>
  <button class="ts-tb-icon" data-toolbar-toggle-item data-toolbar-value="italic">...svg...</button>
</div>

<!-- Single-type group: only one item can be active at a time -->
<div data-toolbar-toggle-group data-toolbar-type="single">
  <button data-toolbar-toggle-item data-toolbar-value="left" data-toolbar-pressed="true">...</button>
  <button data-toolbar-toggle-item data-toolbar-value="center">...</button>
</div>
Events fire on the root element — listen with toolbar:toggle and toolbar:button
03

Single vs Multiple Toggle Groups

type="single" · type="multiple" · allowDeselect
type="single" — only one active (default: cannot deselect)
type="single" + allowDeselect: true — clicking active item deselects it
type="multiple" — any combination active 
<!-- allowDeselect via data-plugin-options -->
<div data-plugin-toolbar
     data-plugin-options='{"allowDeselect":true}'>
  <div data-toolbar-toggle-group data-toolbar-type="single">
    <button data-toolbar-toggle-item data-toolbar-value="edit" data-toolbar-pressed="true">Edit</button>
    <button data-toolbar-toggle-item data-toolbar-value="preview">Preview</button>
  </div>
</div>
Click items to see selection state — log updates on every toolbar:toggle event

Dark Theme

dark: true · ts-toolbar--dark · auto html.dark
Via option: dark: true
Queue
Via class: ts-toolbar--dark (no JS option needed) 
<!-- Via option -->
<div data-plugin-toolbar
     data-plugin-options='{"dark":true}'>...</div>

<!-- Via class — works even without JS options -->
<div data-plugin-toolbar class="ts-toolbar--dark">...</div>

/* Auto-applies when html.dark is present (PluginDarkMode):
   html.dark .ts-toolbar:not(.ts-toolbar--light) { dark vars } */
The teal accent color replaces orange in dark mode — override with --ts-tb-on-bg
06

Disabled States

data-toolbar-disabled · instance.disable() / enable()
Mixed disabled — keyboard skips disabled items automatically 
<!-- Static: attribute in markup -->
<button data-toolbar-button data-toolbar-disabled="true">Paste</button>

// Dynamic: via instance API
const tb = $('#my-toolbar').data('__pluginToolbar');
tb.disable('paste');   // by data-toolbar-value
tb.enable('paste');    // re-enable and restore roving tabindex
Disabled items are skipped by arrow-key navigation — roving tabindex updates automatically
07

Size Modifiers

size: "sm" · default · size: "lg"
Small — 28 px item height
Default — 34 px item height
Large — 40 px item height 
<div data-plugin-toolbar data-plugin-options='{"size":"sm"}'>...</div>
<div data-plugin-toolbar>...</div>
<div data-plugin-toolbar data-plugin-options='{"size":"lg"}'>...</div>

/* Sizes map to modifier classes:
   .ts-toolbar--sm  → 28 px items, 8 px padding, 0.81rem font
   (default)        → 34 px items, 10 px padding, 0.875rem font
   .ts-toolbar--lg  → 40 px items, 14 px padding, 0.94rem font */
All three sizes share the same token set — override --ts-tb-item-h to add custom sizes
08

Programmatic Control

.manual · instance API · getValues / setValue / clearGroup
— waiting for init — 
// Add .manual to suppress auto-init
<div data-plugin-toolbar class="manual" id="tb">...</div>

// Initialize manually
$('#tb').themestrapPluginToolbar({ ariaLabel: 'My toolbar' });

// Get instance
const tb = $('#tb').data('__pluginToolbar');

// Read values
tb.getValues('#tg-env');          // → "prod" (single)
tb.getValues('#tg-flags');        // → ["debug"] (multiple)

// Set values
tb.setValue('staging', '#tg-env');
tb.setValues(['verbose', 'dryrun'], '#tg-flags');

// Clear selections
tb.clearGroup('#tg-flags');

// Teardown
tb.destroy();   // restores initialHTML, removes events, removes stylesheet if last instance
Events appear here

Options Reference

Option Type Default Description
orientationString"horizontal""horizontal" or "vertical". Controls arrow-key axis and separator direction.
loopBooleantrueArrow-key navigation wraps from last item back to first and vice-versa.
dirString"ltr""ltr" or "rtl". Flips the arrow key → previous/next mapping for right-to-left layouts.
ariaLabelString"Toolbar"Sets aria-label on the root element (only when no aria-label is already present in markup).
sizeStringnullnull, "sm", or "lg". Adds .ts-toolbar--sm or .ts-toolbar--lg.
darkBooleanfalseApply the dark colour scheme. Equivalent to adding .ts-toolbar--dark in markup. Auto-applies under html.dark even when false.
fullBooleanfalseStretch the toolbar to 100% width (.ts-toolbar--full). Items wrap to new lines when needed.
allowDeselectBooleanfalseIn type="single" groups, allow clicking the active item to deselect it (producing no selection).
onToggleFunctionnullfn(value, pressed, groupEl) — called after a toggle item state changes.
onButtonFunctionnullfn(value, buttonEl) — called when a regular button is clicked.
onLinkFunctionnullfn(value, linkEl) — called when a link item is clicked.
