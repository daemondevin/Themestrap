PluginSortable

Drag and drop reordering for lists, rows and grids, with mouse, touch and keyboard. Lists that share a group name accept each other's items, which is how a card moves from one column to another. Initialize with data-plugin-sortable or $.fn.themestrapPluginSortable().

1

A basic list

data attribute

With no options the whole item is the handle. Drag any row up or down, and press Escape mid drag to put it back. On a phone, press and hold a row to pick it up: a quick swipe scrolls the page as usual. Links, buttons and form fields inside an item still work, because a press on them never starts a drag.

Drag handles and the keyboard

handle

With handle set, only the grip starts a drag, so the rest of the row can hold text people want to select, and on a phone the grip responds at once. Make the grip a <button> and it can be reached with Tab: press Up or Down on it to move the row. The plugin gives each grip an aria-label that explains this, unless it already has one.

3

Connected lists

group

Three lists with the same group name. Drag a card into another column: the column under the pointer gets a dashed outline. When a card changes lists, ts.sortable.sort fires on both lists with the same detail, and detail.order is the order of the list it landed in.

    Saving the new order

    onSort · toArray()

    Callbacks can't go in a data attribute, so this list is initialized from script with .manual. onSort runs after every drop that changed something, with the same detail as the event. Here it builds the request body you would send to your server. Nothing is actually sent.

    • Getting started #12
    • Installation #7
    • Configuration #31
    • Deployment #4
    Request body: drag a row to see it
    $('#pages').themestrapPluginSortable({
    handle: '.grip',
    onSort: function (detail) {
        $.post('/admin/pages/order', { order: detail.order.join(',') });   // "7,12,31,4"
    }
});

    Public API

    refresh · enable · disable · toArray

    Items added after init can't be dragged until you call refresh(), which marks them as items and gives their grip the handle class and aria-label. Methods can be called through the instance or by name through the jQuery method.

    • Alpha
    • Bravo
    const list = $('#list').data('__pluginSortable');

$('#list').append('<li data-id="c"><button class="grip" type="button"></button> Charlie</li>');
list.refresh();          // marks the new item and its handle

list.disable();          // presses no longer start a drag, the grips fade
list.enable();
list.toArray();          // ['a', 'b', 'c']

$('#list').themestrapPluginSortable('disable');   // the same, by name

    CSS custom properties

    --ts-sort-*

    Two tokens: the tint of the item being dragged and the color of the dashed outlines. With a skin loaded they follow its accent. Set them on the list or any ancestor to override. Everything else is your own list styling.

}

    Destroy and re-initialize

    destroy()

    destroy() unbinds every handler, removes the classes it added, leaves the group, and keeps the items in their current order. The injected stylesheet goes once the last instance on the page is destroyed.
