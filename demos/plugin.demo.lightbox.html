themestrap.plugin.lightbox.js

Lightbox Plugin

Zero-dependency lightbox for images, video, YouTube, Vimeo, and iframes. Galleries, captions, keyboard/swipe nav, and a full programmatic API — no external libraries required.

Single Image

Basic trigger — wrap any element in an anchor with data-plugin-lightbox 
<a href="photo-full.jpg"
   data-plugin-lightbox
   data-caption="Rolling hills at dawn">
  <img src="photo-thumb.jpg" alt="Thumbnail">
</a>

Image Gallery

Linked triggers via data-lightbox-group — arrow keys, click arrows, or swipe 
<!-- All items sharing the same group= string form one gallery -->
<a href="full-1.jpg" data-plugin-lightbox data-lightbox-group="nature" data-caption="...">...</a>
<a href="full-2.jpg" data-plugin-lightbox data-lightbox-group="nature" data-caption="...">...</a>

Caption Sources

data-caption, title attribute, or img alt — resolved in that order
data-caption
title attr
img alt
no caption
 
<!-- Priority: data-caption > title > img[alt] > (empty) -->
<a data-caption="Explicit caption" ...>...</a>
<a title="From title attr" ...>...</a>
<a ...><img alt="From img alt"></a>

YouTube Embed

Point href at any youtube.com or youtu.be URL — plugin auto-detects and builds the embed 
<!-- Full URL or short link — both work -->
<a href="https://www.youtube.com/watch?v=kKr1eSjF-7Q"
   data-plugin-lightbox
   data-caption="Big Buck Bunny">
  <img src="https://img.youtube.com/vi/kKr1eSjF-7Q/mqdefault.jpg" alt="...">
</a>

Programmatic API

Initialize manually, drive via JS, listen to callbacks 
// Manual init — skip auto-init by adding .manual class
const lb = $('#trigger').themestrapPluginLightbox({
  group: 'api-gallery',
  onOpen:  (item, idx) => console.log('opened', idx),
  onClose: ()          => console.log('closed'),
});

// Public methods
lb.open(0);    // open at index
lb.next();     // advance
lb.prev();     // go back
lb.goTo(2);    // jump to index
lb.isOpen();   // → boolean
lb.close();
lb.destroy();

Options via data-plugin-options

JSON options object on the trigger element 
<!-- Inline JSON (single-quoted attr, double-quoted keys) -->
<a href="large.jpg"
   data-plugin-lightbox
   data-plugin-options='{"closeOnBackdrop": false, "mediaWidth": 800}'
   data-caption="Must use × button to dismiss">
  Open
</a>

Non-Anchor Triggers

Any element works — use data-src for the media URL when not an <a>
<span> trigger (data-src)
<div> trigger (data-src) 
<!-- href= is preferred for <a>. For anything else, use data-src= -->
<span data-plugin-lightbox
      data-src="photo.jpg"
      data-caption="Span trigger">
  Open image
</span>

Callbacks

onOpen, onClose, onItemLoad — fire on lifecycle events 
$('#trigger').themestrapPluginLightbox({
  group: 'cb-gallery',
  onOpen:     (item, idx) => log(`opened index ${idx}: ${item.src}`),
  onClose:    ()          => log('lightbox closed'),
  onItemLoad: (item, idx) => log(`item ${idx} loaded`),
});
