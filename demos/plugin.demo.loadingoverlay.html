Themestrap Plugin

Loading Overlay

A flexible loading overlay supporting seven built-in animation styles, progress indicators, messages, runtime controls, backdrop customization, blur, automatic hiding, accessibility attributes, and dark-mode aware backgrounds.

Animation Types

PluginLoadingOverlay provides seven built-in animation types. The buttons below all reuse the same page-level overlay instance, changing its animation at runtime.

Spinner

A classic rotating spinner.

Ring

A rotating dual-arc ring.

Pulse

A circular loader that expands and contracts.

Ripple

Two expanding rings create a ripple effect.

Dots

Three independently bouncing dots.

Bars

Five animated equalizer-style bars.

Orbit

Two dots orbit around a shared axis.

Element Overlay

An overlay does not have to cover the entire page. Attach it directly to a component to indicate that only that portion of the interface is busy.

Example Content Panel

This panel has its own LoadingOverlay instance. Showing this overlay does not interfere with the page-level loader.

const loader = $('#content-loader') .themestrapPluginLoadingOverlay({ type: 'ring', message: 'Loading content...' }) .data('__pluginLoadingOverlay'); loader.show();

Messages

Messages can be supplied during initialization or changed dynamically with setMessage().

Static Message

The message is supplied when the shared page loader is configured for this demonstration.

Runtime Message

The same overlay can change its message while it remains visible.

Progress Overlay

The progress option adds a built-in progress bar. Its value can be updated at runtime with setProgress().

Processing Data

This element has an independent progress-enabled overlay.

const loader = $('#progress-loader') .themestrapPluginLoadingOverlay({ type: 'bars', message: 'Processing...', progress: true, progressValue: 0 }) .data('__pluginLoadingOverlay'); loader.setProgress(50);

Appearance & Customization

Loader color, backdrop color, size, animation duration, and backdrop blur can all be customized.

Custom Appearance

Large loader with a custom color and dark backdrop.

Blurred Backdrop

Uses the CSS backdrop-filter feature through the plugin's blur option.

loader .setSize('lg') .setColor('#0088CC') .setBackdrop('rgba(0,0,0,.78)');

Automatic Behavior

The autoHide option can automatically hide an overlay after a specified number of milliseconds.

loader .setType('pulse') .setMessage('Please wait...') .show(); setTimeout(function () { loader.hide(); }, 2500);

Lifecycle Events

LoadingOverlay emits native custom events when showing and hiding. This example monitors all four lifecycle events.

Waiting for LoadingOverlay events...
$('body').on( 'show.ts.loadingoverlay', function () { console.log('show'); } ); $('body').on( 'shown.ts.loadingoverlay', function () { console.log('shown'); } ); $('body').on( 'hide.ts.loadingoverlay', function () { console.log('hide'); } ); $('body').on( 'hidden.ts.loadingoverlay', function () { console.log('hidden'); } );

Configuration

Available initialization options exposed by the plugin.

Option Default Description
type 'spinner' spinner, ring, pulse, ripple, dots, bars, or orbit.
message '' Text displayed beneath the loader.
ariaLabel 'Loading' Accessible label applied to the overlay.
backdrop null Custom CSS background color.
color null Loader and message color.
size 'md' sm, md, lg, or any CSS length.
duration 800 Animation cycle duration in milliseconds.
fadeDuration 200 Fade transition duration in milliseconds.
blur 0 Backdrop blur amount in pixels.
autoShow false Automatically show after initialization.
autoHide 0 Automatically hide after the specified duration.
progress false Enable the built-in progress bar.
progressValue 0 Initial progress value from 0–100.
lockScroll true Prevent body scrolling during body-level overlays.
zIndex 9000 CSS z-index applied to the overlay.
