02

Custom Toolbar & Sizing

toolbar · placeholder · minHeight

Pick the commands with the toolbar array. Separators ("|") are optional, groups are derived automatically. Numbers for minHeight are treated as pixels.


<div data-plugin-richeditor
     data-plugin-options='{"toolbar":["bold","italic","|","link"],
                           "placeholder":"Short reply…",
                           "minHeight":120}'></div>
Only bold, italic, and link are enabled. Ctrl/⌘+K still opens the link dialog.
03

No Toolbar, Capped Height

toolbar: false · maxHeight

With toolbar: false neither PluginToolbar nor PluginDialog is required or built. The browser's native Ctrl/⌘+B I U shortcuts still work. The area scrolls after maxHeight.


<div data-plugin-richeditor
     data-plugin-options='{"toolbar":false,"placeholder":"Add a comment…",
                           "minHeight":72,"maxHeight":150}'></div>
Type a few lines to watch the scroll cap kick in.
04

Links, Editing & URL Safety

linkTarget · allowedProtocols

Markup inside the host becomes the initial content. Put the caret inside the link and press Ctrl/⌘+K to edit or remove it. Try example.com (gets https://), me@example.com (gets mailto:) and javascript:alert(1) (refused).

Read the Themestrap docs, then select any text and add your own link.


<div data-plugin-richeditor
     data-plugin-options='{"linkTarget":"_blank",
                           "allowedProtocols":["http","https","mailto","tel"]}'>
    <p>Read the <a href="https://themestrap.dev/docs">Themestrap docs</a>.</p>
</div>
linkTarget is currently "_blank".
05

Programmatic API

.manual · instance methods

The host carries .manual, so auto-init skips it and the page initializes it with callbacks. destroy() writes the current content back into the host, so re-initializing keeps your work.


$('#re-api').themestrapPluginRichEditor({
    placeholder: 'Try the buttons below…',
    onChange: function (html) { console.log('change', html); }
});

// Retrieve the instance from a fresh selection, never off the init call
const editor = $('#re-api').data('__pluginRichEditor');

editor.setContent('<p>Hello <strong>world</strong></p>');
editor.getContent();   // '<p>Hello <strong>world</strong></p>'
editor.getText();      // 'Hello world'
editor.isEmpty();      // false
editor.disable();
editor.enable();
editor.clear();
editor.destroy();

06

Form Integration

onChange → hidden field

The editor is not a native form control, so a hidden field mirrors its HTML through onChange. This is the pattern the mailbox compose page uses.


$('#re-form').themestrapPluginRichEditor({
    placeholder: 'Write your message…',
    onChange: function (html) { $('#compose-body').val(html); }
});

$('#compose-form').on('submit', function (e) {
    e.preventDefault();
    const editor = $('#re-form').data('__pluginRichEditor');
    if (editor.isEmpty()) { return; }        // getContent() is '' when empty
    send({ subject: $('#compose-subject').val(), body: editor.getContent() });
});
Submit the form to see the payload.
07

Theming

data-bs-theme · --ts-re-* tokens

The editor follows prefers-color-scheme, html.dark / [data-bs-theme="dark"], and an explicit [data-bs-theme="light"] override. This stage is forced light. The second editor overrides tokens on its own wrapper.


.re-brand {
    --ts-re-bg:           #fff7f0;
    --ts-re-border:       rgba(232,103,42,.35);
    --ts-re-border-focus: #e8672a;
    --ts-re-toolbar-bg:   rgba(232,103,42,.08);
    --ts-re-link:         #b8481a;
    --ts-re-radius:       14px;
    --ts-re-padding:      18px 20px;
}
The link dialog lives on <body>, so wrapper-level tokens do not reach it. Set the tokens on :root to restyle the dialog too.
