Six different flavors, one plugin.

Same plugin, same init pattern. Color, size, pattern, and behavior are all driven by data-plugin-options. Every bar in the grid below is live and animated.

Color

Color variants

Seven semantic variants driven by the color option: primary, secondary, success, warning, danger, info, and dark. All map to the Themestrap accent palette.

Size

Size variants

Four track heights via the size option. xs (3 px) and sm (5 px) are perfect for compact UIs. The default md (8 px) is a safe all-rounder. Use lg (16 px) when you want a label to fit inside the fill.

xs — 3 px
sm — 5 px
md — 8 px (default)
lg — 16 px
Pattern

Striped & animated

striped: true overlays diagonal stripes on the fill. Add animated: true (which implies striped) and the stripes sweep endlessly — the standard "transfer in progress" affordance. Both work with every color and size.

striped only
animated stripes — success
animated stripes — danger
Loading

Indeterminate state

When progress can't be quantified — waiting for a server response, scanning a queue, processing an upload of unknown size — set indeterminate: true. The value option and label are ignored; aria-busy="true" is applied automatically.

primary
info
danger + striped
Label

Value label

label: true renders a live percentage inside the fill that counts up alongside the fill animation. Customise the text with labelFormat — the {value} token is replaced with the rounded integer. The label hides automatically for xs and sm bars where there's no room.

default format — "{value}%"
"{value} / 10 tasks done"
"{value} GB used"
Shape

Square corners

Bars are pill-shaped by default (rounded: true). Set rounded: false for flush right-angle ends — useful in dense tables, admin dashboards, or wherever sharp geometry is a better fit for the surrounding design.

rounded: true (default)
rounded: false
rounded: false + animated

Event visibility.

The playground bar fires progressbar:change on every set() call and progressbar:complete when the fill reaches 100%. Both are native CustomEvents that bubble — listen from any ancestor element.
