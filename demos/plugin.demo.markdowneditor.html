Default Writing Surface

data-plugin-markdowneditor

Zero options. A plain textarea gains a toolbar, a live word count, and smart typing: Enter continues lists and quotes, Tab indents list items, Ctrl/⌘+B I K format. The textarea stays the source of truth, so a normal form post keeps working.

02

Split View & Image Upload

view · imageUpload

Write on the left and see the rendered result on the right. Paste or drop an image onto the editor, or use the image button: imageUpload receives the file and returns a URL (or a Promise of one). This demo turns the file into a data URL; a real site would post it to the server.

$('#me-split').themestrapPluginMarkdownEditor({
    view: 'split',
    minHeight: 320,
    imageUpload: function (file) {
        return new Promise(function (resolve, reject) {
            var reader = new FileReader();
            reader.onload  = function () { resolve(reader.result); };
            reader.onerror = reject;
            reader.readAsDataURL(file);
        });
    }
});

03

Custom Toolbar, No Preview

toolbar · preview · statusBar

Choose commands with the toolbar array, and drop the preview pane entirely with preview: false. "|" separates groups, "spacer" pushes the rest to the right.

$('#me-custom').themestrapPluginMarkdownEditor({
    preview: false,
    statusBar: false,
    minHeight: 120,
    placeholder: 'A short reply…',
    toolbar: ['bold', 'italic', 'code', '|', 'link', 'spacer', 'fullscreen']
});
04

Custom or Server-Side Renderer

renderer

By default the preview uses PluginMarkdown. Pass renderer to use anything else: a different parser, or a server round trip so the preview matches the published page exactly. The function may return HTML or a Promise of HTML, and only the latest result is applied. This demo fakes a slow server.

$('#me-renderer').themestrapPluginMarkdownEditor({
    view: 'split',
    minHeight: 180,
    renderer: function (md) {
        return fetch('/admin/render', { method: 'POST', body: new URLSearchParams({ body: md }) })
            .then(function (r) { return r.json(); })
            .then(function (j) { return j.html; });
    }
});
05

API & Events

getValue · insert · command

Drive the editor from your own UI. Every call below goes through the public API, and the log shows the native CustomEvents the editor dispatches. Ctrl/⌘+S raises ts.markdowneditor.save without touching the browser's save dialog.

const ed = $('#me-api').data('__pluginMarkdownEditor');

ed.command('bold');            // toggle **bold** around the selection
ed.insert('\n---\n');          // insert at the caret
ed.setView('split');
ed.fullscreen(true);
ed.getValue();                 // Markdown string
ed.getHtml();                  // rendered HTML

document.getElementById('me-api')
    .addEventListener('ts.markdowneditor.save', function (e) { /* post the form */ });

Theming

--ts-me-*

Every color is a custom property with a light and a dark default, resolved through the standard three-tier pattern. Set tokens on the editor, or on :root to restyle them all. The typing font is a token too.

.writer {
    --ts-me-border-focus: #e8672a;
    --ts-me-radius:       14px;
    --ts-me-font:         Georgia, serif;
    --ts-me-font-size:    17px;
    --ts-me-padding:      22px 26px;
}
