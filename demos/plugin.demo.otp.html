PluginOtp

Digit-segmented OTP / PIN input with auto-advance, backspace navigation, paste handling, complete events, error and valid states, and size variants. No dependencies beyond jQuery — CSS injected lazily on first use.

Numeric · 6 Digits

Default numeric length: 6
Events will appear here…
// Init
$('#otp1').themestrapPluginOtp();

// Listen for complete
$('#otp1').on('ts.otp.complete', function(e) {
    console.log(e.detail.value); // "483920"
});

PIN · 4 Digits · Auto-Submit

length: 4 autoSubmit: true separator: –
Fill all 4 digits to trigger auto-submit
Events will appear here…
$('#otp2').themestrapPluginOtp({
    length:      4,
    autoSubmit:  true,
    separator:   '–',
});

$('#otp2').on('ts.otp.submit', function(e) {
    console.log('submitted:', e.detail.value);
});

Alphanumeric · Uppercase · Large

alphanumeric uppercase: true size: lg length: 5 
$('#otp3').themestrapPluginOtp({
    length:     5,
    type:       'alphanumeric',
    uppercase:  true,
    size:       'lg',
    label:      'Backup code',
    hint:       'Check your recovery sheet.',
});

Small Variant · Light Theme

size: sm theme: light 
$('#otp4').themestrapPluginOtp({
    length:  6,
    size:    'sm',
    theme:   'light',
});

Configuration Options

OptionTypeDefaultDescription
lengthnumber6Number of digit boxes rendered.
typestring'numeric''numeric' or 'alphanumeric'. Numeric uses tel input type and numeric keyboard on mobile.
uppercaseboolfalseForces alphanumeric input to uppercase.
autoSubmitboolfalseWhen true, dispatches ts.otp.submit the moment all boxes are filled.
separatorstring''Character rendered between the left and right halves (e.g. '-'). Only drawn when length is even.
labelstring''Label text above the inputs.
hintstring''Helper text below the inputs.
ariaLabelstring'One-time code'ARIA label on the wrapper group element.
sizestring'''', 'sm', or 'lg'. Adjusts box dimensions and font.
themestring'''' (dark) or 'light'. Swaps CSS variable set for light backgrounds.
