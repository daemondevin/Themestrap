PluginReveal

Fades elements in as they scroll into view, and gives a banner a slow parallax drift. Everything is set as element styles from script, so no stylesheet is injected and the plugin works under a strict Content Security Policy. Initialize with data-plugin-reveal or $.fn.themestrapPluginReveal().

Elements already on screen when the page loads are left as they are, so nothing flashes. That's why the examples start below this first screen. Each Replay button scrolls its card out of view and back.

Your system asks for reduced motion, so Reveal shows every element straight away and the banners don't move. That is the plugin working as intended. Turn off reduced motion in your system settings to see the effects.

A staggered row

stagger

Six tiles with stagger: 90. Elements that start appearing within 100ms of each other are numbered in page order from zero, so each tile waits 90ms longer than the one before it, every time, however many elements appeared earlier on the page.

Two+90ms

Four+270ms
Five+360ms
Six+450ms

Timing, threshold and your own transform

distance · duration · delay · threshold

The left tile travels further and slower after a short wait. The right one waits until 60% of it is on screen (threshold: 0.6) instead of 12%, so it appears later as you scroll. The pill below is centered with transform: translateX(-50%): Reveal slides it in on top of that transform and leaves it centered.

4

Parallax background

parallax · speed

With parallax: true the element's background moves more slowly than the page. Scroll and watch the stars drift behind the heading. Use a background that repeats or is taller than the element, or its edges will show.

Background driftspeed 0.35

<section class="banner"
         style="background-image: url(img/night-sky.jpg); background-size: cover;"
         data-plugin-reveal data-plugin-options='{"parallax": true, "speed": 0.35}'>
    <h3>Background drift</h3>
</section>
5

Parallax on a child element

target

target moves a child, such as an <img>, instead of the background. The child is only ever shifted upwards while the banner is on screen, so it needs extra height at the bottom: calc(100% + 30vh) covers any speed up to 0.3.

Layer driftspeed 0.25, target .layer

<section class="banner" data-plugin-reveal
         data-plugin-options='{"parallax": true, "speed": 0.25, "target": ".layer"}'>
    <img class="layer" src="img/hills.jpg" alt="">
    <h3>Layer drift</h3>
</section>
.banner        { position: relative; height: 280px; overflow: hidden; }
.banner .layer { position: absolute; left: 0; top: 0; width: 100%; height: calc(100% + 30vh); object-fit: cover; }
6

Events and the API

ts.reveal.shown · show() · destroy()

ts.reveal.shown fires when an element starts to appear. show() reveals an element at once, without waiting to be scrolled to: the Show waiting elements now button at the top of this page calls it on every element that is set up and still waiting. Elements wired through intObsInit are only set up as they come within 200px of the screen, so ones further down still animate later. destroy() puts the element's own inline styles back, so a waiting element appears immediately and without animation.

LeftfadeInLeft
RightfadeInRight
document.getElementById('promo').addEventListener('ts.reveal.shown', function () {
    console.log('promo is appearing');
});

// a "skip animations" button: show everything that is still waiting
$('[data-plugin-reveal]').each(function () {
    const reveal = $(this).data('__pluginReveal');
    if (reveal && this.style.opacity === '0') reveal.show();
});

$('#promo').themestrapPluginReveal('destroy');   // or by name, through the jQuery method
