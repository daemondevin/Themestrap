Toggle plugin

jQuery slideDown/Up accordion using .toggle + label or .toggle-title markup

Default Accordion mode Start active Preview paragraph
01

Default — multiple panels open simultaneously

isAccordion: false

Include jQuery, Bootstrap 5, themestrap.js, and the plugin file. Add the .toggle-wrapper container and as many .toggle rows as you need. Each row has a label or .toggle-title and a .toggle-content sibling.

The plugin scans > .toggle children of the initialized wrapper. The trigger can be a <label> or any element with class .toggle-title. Content goes inside .toggle-content.

The only dependency is core jQuery — no additional plugins needed. Animation uses jQuery's built-in slideDown / slideUp. Duration is configurable via the duration option.

<div id="my-toggle">
  <div class="toggle">
    <label>Section title</label>
    <div class="toggle-content"><p>Content.</p></div>
  </div>
</div>

$('#my-toggle').themestrapPluginToggle();
// multiple panels can be open at once

03

Start active — add .active to a row

class="toggle active"

This panel is closed when the page loads.

Adding the .active class to a .toggle row before initialization causes the plugin to slide that panel open immediately. Use this for panels that should be visible by default.

This panel is also closed when the page loads.

<div class="toggle active">   <!-- starts open -->
  <label>Open on load</label>
  <div class="toggle-content">…</div>
</div>

$('#tg-03').themestrapPluginToggle();
// second panel starts expanded via .active class
