CursorEffect plugin

Custom cursor overlay — ring + dot, hover morphs via data attributes, nine colour themes, three size variants

Active cursor Hover morphs Colours API
01

Active cursor — move your mouse anywhere on this page

initialized on <body>

The ring + dot overlay is active across the whole page.
Move your mouse around to see it track your cursor. 

// Initialize once on body — the overlay is global
$('body').themestrapPluginCursorEffect({
  color:   'default',  // colour theme
  size:    'default',  // 'small' | 'default' | 'big'
  hideNative: true,  // hide the OS cursor
});

// The plugin appends .cursor-outer and .cursor-inner to body.
// Styles are injected lazily from build().
// cursor overlay active on page load
02

Hover morphs — data attribute triggers shape changes

data-cursor-effect-hover
data-cursor-effect-hover="fit"
Ring scales to enclose the element exactly — useful on buttons and links
data-cursor-effect-hover="plus"
Ring morphs into a plus / crosshair shape — useful on interactive content areas
No data attribute
Default ring + dot — no morph applied 
// Add to any element — the cursor reacts on mouseenter/mouseleave
<button data-cursor-effect-hover="fit">Hover me</button>
<div    data-cursor-effect-hover="plus">Hover me</div>

// Morphs are CSS-driven — no JS per element beyond the data attribute.
// hover each zone above to see the morph

04

API — size, show/hide, destroy

setSize · show · hide · destroy · reinit

Use the buttons below to control the cursor overlay programmatically.

const cursor = $('body').data('__cursorEffect');

cursor.setSize('small');    // 'small' | 'default' | 'big'
cursor.show();                // make overlay visible
cursor.hide();                // hide without destroying
cursor.destroy();             // remove overlay + restore native cursor
// click a button above
