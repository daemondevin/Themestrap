ScrollToTop plugin

Fade-in scroll-to-top button — configurable threshold, label, easing, target element, and mobile visibility

Page scroll Element scroll Custom label API
01

Page scroll — button appears after scrolling past threshold

scrollAfter: 300

The default scroll-to-top button is fixed at the bottom-right of the viewport. It appears once the page is scrolled past scrollAfter pixels (300 px by default).

Scroll the page down to see the button appear, then click it to return to the top. 

<div id="scroll-to-top"></div>

$('#scroll-to-top').themestrapPluginScrollToTop({
  scrollAfter:    300,       // px from top before button fades in
  scrollDuration: 700,       // ms for the scroll animation
  easing:         'swing',  // jQuery easing (easeOutBack if loaded)
  visibleMobile:  true,     // show on mobile viewports
});
// scroll down 300 px to reveal the button
02

Element scroll — scoped to an overflow container

scrollTarget: '#scroll-box'

The plugin can scope scrolling to any overflow container. A local scroll-to-top button will appear inside the container after scrolling past the threshold.

Scroll position: 0 px

Scroll down inside this box to trigger the scroll-to-top button. The button will appear after the inner scroll position exceeds the configured threshold.

03

Custom label — text or HTML content inside the button

label option

The default label is an arrow icon. Any text or HTML can be substituted.

↑ arrow (default)
text label
emoji label 
// Default arrow icon:
$('#stt').themestrapPluginScrollToTop();

// Text label:
$('#stt').themestrapPluginScrollToTop({ label: 'Back to top' });

// Custom HTML:
$('#stt').themestrapPluginScrollToTop({ label: '🚀' });
// scroll down to see all three button variants
04

API — show · hide · scrollTo · destroy

programmatic control

Call methods directly on the stored instance without waiting for the scroll threshold to be crossed.

const inst = $('#stt-wrapper').data('__scrollToTop');

inst.show();      // force-show the button
inst.hide();      // force-hide the button
inst.scrollTo();  // fire the scroll animation immediately
inst.destroy();   // remove button and unbind events
// click a button above
