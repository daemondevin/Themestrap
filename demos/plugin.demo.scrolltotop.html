PluginScrollToTop

One back-to-top button for the whole page. It fades in once the page has scrolled past an offset and glides back to the top when clicked. Scroll this page to see the live one in the bottom right corner.

03 Restyle It html .scroll-to-top

The look comes from css/themestrap-elements.css. Override html .scroll-to-top to restyle it. The toggle switches the live button on this page between the stock tab and a round floating button.

style 
html .scroll-to-top {
    width: 46px;
    height: 46px;
    min-width: 0;
    padding: 0;
    right: 24px;
    bottom: 24px;
    border-radius: 50%;
    display: grid;
    place-items: center;
    background: #0e2238;
    color: #20e2d7;
}

/* Worth keeping: a hidden button is only transparent, so stop it taking clicks */
html .scroll-to-top:not(.visible) { pointer-events: none; }
04 JavaScript API defaults · initialize · $el · options

PluginScrollToTop is a single object on themestrap, not a jQuery plugin: there is no $.fn.themestrapPluginScrollToTop and no per-element instance. Call initialize() once; a second call adds a second button.

const stt = themestrap.PluginScrollToTop;

stt.defaults;            // change before initialize() runs
stt.initialize({ offset: 300, easing: 'swing' });   // once, without init.js
stt.$el;                 // the button, as a jQuery object
stt.options;             // the merged options

// Track clicks
stt.$el.on('click', () => analytics.track('scroll_to_top'));

// Respect reduced motion
if (matchMedia('(prefers-reduced-motion: reduce)').matches) {
    stt.defaults.delay = 0;
}

Keep scrolling. The button fades in once you pass 300 px and stays in the bottom right corner until you return to the top.

The plugin listens to the window's scroll event and toggles one class. The fade is pure CSS: the stock style takes the button from transparent to 75% opacity, and to full opacity on hover.

Clicking animates the page back to the top over the delay option with jQuery's animate() and the easing curve. The default easeOutBack overshoots slightly before settling, which is why jQuery Easing is part of this page.
