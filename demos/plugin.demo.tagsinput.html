PluginTagsInput

A zero dependency tag and recipient field that wraps a plain text input. Tags are committed with Enter, comma, semicolon or Tab, validated as email addresses by default, and kept in sync with the source input as a comma separated string. Initialize with data-plugin-tagsinput or $.fn.themestrapPluginTagsInput().

1

Basic email recipients

data attribute

Pre-filled from the input value. Type an address and press Enter, comma, semicolon or Tab. Try not-an-email to see the invalid shake. Backspace on an empty field removes the last tag.

<input type="text" id="to"
       data-plugin-tagsinput
       value="ada@example.com, grace@example.com">
2

Per element options

data-plugin-options

Options go in data-plugin-options as single quoted JSON. This field accepts free form keywords by turning email validation off.

<input type="text"
       data-plugin-tagsinput
       data-plugin-options='{"validateEmail": false, "placeholder": "Add a keyword..."}'
       value="jquery, bootstrap, zero-build">
3

Public API

addTag / removeTag / getTags / clearTags

Initialized manually with the .manual class. The instance is stored under __tagsinput. Tags added through the API fire events unless the second argument is true (silent).

Source value: 
const $el = $('#to').themestrapPluginTagsInput({ validateEmail: true });
const ti  = $('#to').data('__tagsinput');

ti.addTag('grace@example.com');          // fires ts.tagsinput.add
ti.addTag('hopper@example.com', true);   // silent, no event
ti.removeTag('grace@example.com');       // fires ts.tagsinput.remove
ti.getTags();                            // ['ada@example.com', 'hopper@example.com']
ti.clearTags();                          // empties the field, fires no event
4

Form submission

source input sync

The hidden source input keeps the value as a, b, c, so a normal form post just works. Split on the server with explode(',', ...) and trim each entry.

Submit the form to see the serialized values.
<form method="post">
    <input type="text" name="to" data-plugin-tagsinput>
    <input type="text" name="cc" data-plugin-tagsinput
           data-plugin-options='{"placeholder": "Add Cc..."}'>
    <button type="submit">Send</button>
</form>
5

Pasting lists

separators · maxTags · normalize

Paste a list and every item becomes its own tag: a, b, c, one per line, or a column copied from a spreadsheet. A single pasted word is inserted as text, so you can still edit it before pressing Enter. Text that arrives any other way (drag and drop, a phone keyboard) is split the same way. Duplicates and anything over the limit are skipped and reported in the ts.tagsinput.paste event. This field allows 6 tags, ignores case, and strips # and quotes.

$('#keywords').themestrapPluginTagsInput({
    validateEmail: false,
    maxTags:       6,
    ignoreCase:    true,       // "Web" and "web" are one tag
    normalize:     function (t) { return t.replace(/[#"']/g, '').trim(); }
    // separators: ',;\n\t'    what ends a tag (a comma always does)
    // splitOnSpace: 'auto'    follows validateEmail
});

document.getElementById('keywords').addEventListener('ts.tagsinput.paste', function (e) {
    console.log(e.detail.added, e.detail.skipped);   // skipped: [{ tag, reason: 'duplicate' | 'max' | 'invalid' }]
});
6

CSS custom properties

--ts-ti-*

Every colour and radius is a token. Set them on the field or on any ancestor. The defaults are tuned for dark surfaces, so light pages should override the background, border and text tokens as shown on the right.

.theme-amber {
    --ts-ti-bg: rgba(255,159,67,0.05);
    --ts-ti-border: rgba(255,159,67,0.30);
    --ts-ti-border-focus: #ff9f43;
    --ts-ti-radius: 10px;
    --ts-ti-tag-bg: rgba(255,159,67,0.16);
    --ts-ti-tag-text: #ffb870;
    --ts-ti-tag-radius: 6px;
}
7

Destroy and re-initialize

destroy()

destroy() removes the widget, unhides the source input and clears the instance. The source keeps its last value, and the injected stylesheet is removed once the last instance is gone.

State: active
$('#field').data('__tagsinput').destroy();       // tear down
$('#field').themestrapPluginTagsInput({});         // initialize again, reads the value
