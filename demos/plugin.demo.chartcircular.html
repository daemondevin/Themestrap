Themestrap — JS Plugin

PluginChartCircular

Animated circular progress rings drawn directly to a <canvas> element. No external dependencies — reads data-percent, animates on scroll-in via IntersectionObserver, and renders sharp on any display density.

Full reference guide → Source →
Basic

Default ring

175 px, 13 px stroke, round end-cap, 2.5 s easeOutCubic fill.

0%
<div class="chart-host"
     data-percent="78"
     data-plugin-options='{"barColor":"#e8672a","trackColor":"rgba(255,255,255,0.07)","size":175,"lineWidth":13}'>
  <div class="chart-overlay">
    <span class="percent">0</span>%
  </div>
</div>

$('.chart-host').themestrapPluginChartCircular();

Line cap

lineCap controls the arc end treatment. round is the default; butt gives flush ends; square adds a half-stroke-width protrusion.

0%
round
0%
butt
0%

data-plugin-options='{"lineCap":"round"}'   /* default — rounded arc ends */
data-plugin-options='{"lineCap":"butt"}'    /* flush cut at both ends       */
data-plugin-options='{"lineCap":"square"}'  /* square protrusion            */

Track & color options

Set trackColor: false for a floating arc with no background ring. Any CSS color string works for barColor and trackColor.

0%
no track
0%
solid track
0%
thin stroke 
/* Floating arc — no track ring */
{"barColor":"#f5a623","trackColor":false}

/* Solid-filled track */
{"barColor":"#34d399","trackColor":"#064e3b"}

/* Hairline stroke with tinted track */
{"barColor":"#f87171","trackColor":"rgba(248,113,113,0.12)","lineWidth":4,"lineCap":"butt"}

Scale ticks & rotate

scaleColor draws 24 equidistant tick marks outside the track ring. rotate shifts the arc’s zero-point in degrees — 0 is top (12 o’clock), 90 is right.

0%
scale ticks
0%
rotate: 90°
0%
rotate: 180° 
/* 24 tick marks drawn outside the track ring */
{"scaleColor":"rgba(255,255,255,0.2)","scaleLength":6}

/* Shift the arc start-point by 90° and 180° */
{"rotate":90}
{"rotate":180}

Animation speed

Control fill duration via animate.duration in ms. Set animate.enabled: false to skip the rAF loop and snap straight to the target value.

0%
2500 ms (default)
0%
no animation 
{"animate":{"duration":400,"enabled":true}}    /* fast */
{"animate":{"duration":2500,"enabled":true}}   /* default */
{"animate":{"enabled":false}}                  /* instant snap */

Interactive — destroy & re-init

Use the range slider to pick a target, then click Animate. Internally it calls instance.destroy() then re-initializes with the new data-percent value.

0%
initial
ready — drag the slider, then click Animate
/* Destroy and re-init at a new percentage */
const inst = $('#chart-live').data('__chartCircular');
if (inst) inst.destroy();

$('#chart-live')
    .attr('data-percent', newPct)
    .themestrapPluginChartCircular({
        barColor: '#2ab8c8',
        trackColor: 'rgba(255,255,255,0.09)',
        size: 200, lineWidth: 14,
        animate: { duration: 1200, enabled: true }
    });
