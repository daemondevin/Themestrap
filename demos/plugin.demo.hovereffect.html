HoverEffect plugin

Magnetic pull and 3D perspective tilt driven by mouse position — zero vendor dependencies

Magnetic 3D tilt Combined Options
01

Magnetic — element follows the cursor

effect: 'magnetic'

Hover over a card — it will pull toward your cursor

🧲
strength: 0.4
(default)
⚡
strength: 0.8
(stronger)
🪐
strength: 1.4
(maximum)
$('.ef-card').themestrapPluginHoverEffect({
  effect:   'magnetic',
  strength: 0.4,  // 0–2, default 0.4
});
// hover a card to see the pull
02

3D tilt — perspective rotation following the cursor

effect: '3d'

Move your cursor across each card to tilt it in 3D space

🎲
tiltMax: 15°
(default)
🏔️
tiltMax: 30°
(dramatic)
✨
glare: true
tiltMax: 20°
$('.ef-card').themestrapPluginHoverEffect({
  effect:  '3d',
  tiltMax: 15,    // degrees, default 15
  glare:   false, // reflective highlight overlay
});

// with glare overlay:
$('.ef-card').themestrapPluginHoverEffect({
  effect: '3d', tiltMax: 20, glare: true, glareOpacity: 0.3,
});
// hover across a card to see the tilt
03

Combined — magnetic pull + 3D tilt simultaneously

effect: 'magnetic-3d'

Both effects active at once — the card pulls and tilts

🪄
magnetic-3d
strength 0.5 · tilt 20°
🌿
magnetic-3d + scale
strength 0.6 · tilt 18°
$('.ef-card').themestrapPluginHoverEffect({
  effect:   'magnetic-3d',
  strength: 0.5,  // magnetic pull strength
  tiltMax:  20,   // 3D tilt degrees
  scale:    1.05, // scale up on hover (1 = no scale)
  glare:    false,
});
// the combined effect on hover
