Themestrap Component Library

PluginColorPicker

Zero-dependency jQuery color picker with HSV model, alpha channel, preset swatches, EyeDropper API integration, and full keyboard navigation.

1

Default Usage

hex basic 
<input type="text" id="cp-basic" value="#3498db">

<script>
$('#cp-basic').themestrapPluginColorPicker({
    onChange: function(val, inst) {
        console.log('color:', val);
    }
});
</script>

Public API

manual init api 
const inst = $('#cp-api').themestrapPluginColorPicker({
    showEyeDropper: true,
    swatches: ['#e74c3c', '#3498db', '#2ecc71', '#f39c12'],
    onChange: function(val) { /* ... */ },
    onOpen:   function()    { /* ... */ },
    onClose:  function()    { /* ... */ },
}).data('__pluginColorPicker');

inst.open();
inst.close();
inst.toggle();
inst.setColor('#e74c3c');     // accepts hex, rgb, rgba, hsl, named
const val = inst.getColor();  // returns current value in configured format
inst.destroy();
