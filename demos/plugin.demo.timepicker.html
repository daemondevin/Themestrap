A time field with a popover of scrollable hour, minute and AM/PM columns, built to sit beside PluginCalendar. Type "8:30pm" or pick from the columns. The hidden input always holds 24 hour HH:mm.

01

Default (12 hour)

data-plugin-timepicker

Click the field or the clock to open the popover and pick an hour, minutes and AM/PM. Or type: 8:30pm, 830, 20.30 and 9 are all understood. The hidden input always holds the 24 hour value, shown under the field.

hidden input value08:30

<input type="text" name="publish_time" value="08:30"
       data-plugin-timepicker data-plugin-options='{"format": "12"}'>

02

24 Hour, Every 15 Minutes

format: "24" · minuteStep: 15

The popover lists a minute every minuteStep minutes, but typing accepts any minute: enter 07:07 and it is added to the list.


$('#start').themestrapPluginTimePicker({ format: '24', minuteStep: 15 });
03

Empty Start and Keyboard

defaultTime

An empty field stays empty until you choose. The first pick fills the rest from defaultTime. In the field, ↑ ↓ change the minutes (Shift the hour), and Alt+↓ opens the popover. In the popover, arrows move within and between columns.


$('#reminder').themestrapPluginTimePicker({ placeholder: 'Pick a time', defaultTime: '09:00' });
04

Inline

inline: true

Show the columns in the page instead of a popover, for a dedicated "set a time" screen. It updates live.


$('#alarm').themestrapPluginTimePicker({ inline: true });
05

API and Events

getValue · setValue · setNow

The events fire on the original input, with the canonical value and the display text. ts.timepicker.change reports where the change came from.


const tp = $('#meeting').data('__pluginTimePicker');
tp.setValue('8:15pm');     // "20:15"
tp.setNow();
document.getElementById('meeting').addEventListener('ts.timepicker.change', function (e) {
    console.log(e.detail.value, e.detail.display, e.detail.source);   // "20:15", "8:15 PM", "api"
});

Theming

--ts-tp-*

Colors are custom properties with light, dark and explicit-light tiers. They are named so the picker can match PluginCalendar on the same page.


.warm {
    --ts-tp-accent:       #e8672a;
    --ts-tp-border-focus: #e8672a;
    --ts-tp-focus-ring:   0 0 0 3px rgba(232, 103, 42, .25);
    --ts-tp-radius:       999px;
}
