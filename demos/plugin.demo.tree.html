Usage
$('#my-tree').themestrapPluginTree({
  checkbox:   true,
  multiSelect: true,
  data: [
    {
      id: 'admin', text: 'Admin',
      children: [
        { id: 'usr-read',   text: 'Read users'   },
        { id: 'usr-write',  text: 'Write users'  },
        { id: 'usr-delete', text: 'Delete users' }
      ]
    }
  ],
  onSelect: (node, $el) => {
    console.log('checked:', node.id);
  }
});
Behaviour
Clicking a parent checkbox cascades to all descendants. If only some children are checked the parent shows an indeterminate (−) state. getSelected() returns every explicitly checked leaf and folder node.

Usage
$('#my-tree').themestrapPluginTree({
  search: {
    enabled:     true,
    placeholder: 'Filter nodes…',
    fuzzy:       false,  // exact substring
    openFound:   true   // auto-open parents
  },
  data: [...]
});

// Call programmatically:
tree.search('butt');   // highlights matches
tree.search('');      // clears filter

// ts.tree.search event:
el.addEventListener('ts.tree.search', e => {
  console.log(e.detail.term, e.detail.count);
});
Matching modes
Substring — case-insensitive includes() with in-place mark highlighting.
Fuzzy — all characters of the term must appear in order in the node text; useful for keyboard-shortcut-style filtering.
Public API & Events
reference
Methods
const inst = $('#el').data('__pluginTree');

// Expand / collapse
inst.open('nodeId');      // open by id
inst.close($li);          // or pass $li
inst.toggle('nodeId');
inst.openAll();
inst.closeAll();

// Selection
inst.select('nodeId');
inst.deselect('nodeId');
inst.deselectAll();
inst.getSelected();
// → [{ id, data, $el }, ...]

// Search
inst.search('term');
inst.search('');         // reset

// Teardown
inst.destroy();           // restores original HTML
