Themestrap · Plugin

Emoticon data-plugin-emoticonjQuery only

An emoji picker and emoticon converter for chat boxes and message inputs. Typed :) and :fire: become emoji as you type, and a searchable picker keeps your recent emoji on top. Uses the device's own emoji, no images and no vendor dependencies.

01

Chat Box

data-plugin-emoticon · input-group

Put data-plugin-emoticon on the message input. The picker button lands right after it, inside the input group. Pick several emoji in a row, search by name, or use the keyboard: arrows move, Enter picks, Esc closes. A message of one to three emoji is shown big with isEmojiOnly().

AnnWho's up for a game? 🎲

<form id="chat" class="input-group">
    <input type="text" class="form-control" data-plugin-emoticon
           data-plugin-options='{"buttonClass": "btn btn-outline-secondary"}'>
    <button type="submit" class="btn btn-primary">Send</button>
</form>

<script>
$('#chat').on('submit', function (e) {
    e.preventDefault();
    var text = $(this).find('input').val();   // emoticons are already emoji here
    var big = themestrap.PluginEmoticon.isEmojiOnly(text);
});
</script>

Typed Emoticons

shortcuts · shortcodes · button: false

Emoticons swap once a space or punctuation follows them, and only at the start or after a space, so links like http:// and list items like b) stay as typed. Any emoji's name between colons works too, for example :tada: or :thumbsup:. Pressing Backspace right after a swap puts the typed text back. This input has no picker button.

This one also knows (y) from extraShortcuts.


<input type="text" class="form-control" data-plugin-emoticon
       data-plugin-options='{"button": false, "extraShortcuts": {"(y)": "👍"}}'>

Converting Text

PluginEmoticon.convert() · isEmojiOnly() · search()

The static helpers need no instance. Use convert() on messages from people who typed without the plugin, isEmojiOnly() to show short emoji messages big, and search() to build your own suggestions.


var Emoticon = themestrap.PluginEmoticon;
Emoticon.convert('GG :D <3 :trophy:');   // 'GG 😃 ❤️ 🏆'
Emoticon.isEmojiOnly('🎉🎉');             // true
Emoticon.search('heart');                // [{ char: '❤️', name: 'heart', ... }, ...]
Emoticon.lookup(':dice:');               // '🎲'

Options

trigger · categories · closeOnPick · placement

Open the picker from a button of your own with trigger, show only some categories, close after each pick, and place the panel below the input. This textarea takes game night and hearts emoji only.


$('#note').themestrapPluginEmoticon({
    trigger: '#note-emoji',
    categories: ['games', 'hearts'],
    recent: false,
    closeOnPick: true,
    placement: 'bottom'
});

Theming

--ts-emoticon-*

Colors, corners, emoji size and panel size are custom properties with light, dark and explicit-light tiers. Set them on a wrapper, or on :root for every picker. The panel lives in the nearest drawer, modal or offcanvas, else the body, so put the tokens where the panel ends up.


.retro {
    --ts-emoticon-bg:     #fff8e7;
    --ts-emoticon-border: #e8672a;
    --ts-emoticon-accent: #e8672a;
    --ts-emoticon-radius: 4px;
    --ts-emoticon-size:   1.25rem;
    --ts-emoticon-width:  17rem;
}
