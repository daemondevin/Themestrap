PluginImageUpload

A picture picker for one image, such as an avatar or a logo. It shows the current picture, takes a click, a drag and drop or a paste, uploads with a progress bar, and offers a remove button. Initialize with data-plugin-imageupload or $.fn.themestrapPluginImageUpload().

This page has no server, so requests to demo: addresses are answered by a small stand in that keeps your picture in the browser and logs what a real server would receive. Nothing leaves your computer. The sample picture buttons draw a picture and drop it on the widget for you.

1

An avatar

data attribute · shape: circle

Starts with the picture in current. Click the circle or the button to choose a file, or drop one on the circle. Every request carries the entries of data, and csrf goes in both a _csrf field and an X-CSRF-Token header.

<div data-plugin-imageupload
     data-plugin-options='{"endpoint": "/account/avatar", "shape": "circle",
                           "current": "/uploads/avatars/42.jpg",
                           "data": {"kind": "avatar"}, "csrf": "..."}'></div>
{ "ok": true, "url": "/uploads/avatars/42.jpg?v=1731290000" }
2

A logo, starting empty

shape: box · note · maxSize

The box shape is wider than it is tall and fits the whole picture inside it instead of cropping, which suits logos. With no current picture the widget shows its drop hint and no remove button. note adds a line of help, maxSize (in bytes) refuses big files before they are sent, and accept adds SVG to the types this widget takes.

<div data-plugin-imageupload
     data-plugin-options='{"endpoint": "/admin/identity", "shape": "box", "maxSize": 1048576,
                           "accept": "image/png,image/jpeg,image/webp,.svg",
                           "labels": {"type": "Please use a PNG, JPG, WebP or SVG file."},
                           "note": "PNG, JPG, WebP or SVG, up to 1 MB.", "data": {"kind": "logo"}}'></div>
3

When things go wrong

ts.imageupload.error

The plugin checks the type and size in the browser first: a file must match accept (JPG, PNG, GIF and WebP by default) and be no bigger than maxSize. A server can refuse a picture with {"ok": false, "errors": [...]}, and its messages are shown as they are. Every error is shown under the buttons and fires ts.imageupload.error.

Checked in the browser, 200 KB limit
Refused by the server 
document.getElementById('avatar').addEventListener('ts.imageupload.error', function (e) {
    console.warn(e.detail.message);    // the text shown under the buttons
});
{ "ok": false, "errors": ["Pictures must be at least 400 by 400 pixels."] }
4

Pasting a picture

paste

With paste: true, a picture pasted on the page is uploaded. Copy a picture (a screenshot works) and press Ctrl + V, or ⌘ + V on a Mac. Both widgets here have paste on, and each paste goes to just one of them: the one with focus, else the one you used last, else the first on screen. Tab to a widget, or click beside its buttons, then paste. A paste into the text box is left to the text box.

<div data-plugin-imageupload data-plugin-options='{"endpoint": "/account/avatar", "paste": true}'></div>
<div data-plugin-imageupload data-plugin-options='{"endpoint": "/account/cover", "paste": true}'></div>
5

Public API

setImage · getImage · open · remove · disable

setImage() only changes what is shown, for example after the picture was changed somewhere else. It sends nothing and fires no event. remove() asks the server to delete the picture. Methods can be called on the instance or by name through the jQuery method.

$('#avatar').themestrapPluginImageUpload({ endpoint: '/account/avatar', shape: 'circle' });
const upload = $('#avatar').data('__pluginImageUpload');

upload.setImage('/uploads/avatars/42.jpg');   // show a picture, sends nothing
upload.getImage();                            // '/uploads/avatars/42.jpg'
upload.open();                                // the file chooser
upload.remove();                              // POST remove=1, then the empty state
upload.disable();                             // faded, ignores clicks, drops and pastes

$('#avatar').themestrapPluginImageUpload('enable');   // the same, by name
6

CSS custom properties

--ts-iu-*

Size, colors, the box corner radius and the error color are tokens. With a skin loaded the colors and radius follow it. Set them on the widget or any ancestor to override. The buttons are Bootstrap classes by default, and this page passes its own through buttonClass and removeClass.

.profile .ts-iu {
    --ts-iu-size:   9rem;                  /* the circle, and the box's height */
    --ts-iu-accent: #ff9f43;               /* hover, focus, drop target, progress bar */
    --ts-iu-border: rgba(255,159,67,.45);
    --ts-iu-bg:     rgba(255,159,67,.06);
    --ts-iu-muted:  #ffb870;               /* drop hint and note */
    --ts-iu-danger: #ff8f80;               /* error messages */
}
7

Destroy and re-initialize

destroy()

destroy() cancels an upload in progress, unbinds every handler and empties the element. The injected stylesheet goes once the last instance on the page is destroyed. Initialize again with the picture to show.

State: active
const url = $('#avatar').data('__pluginImageUpload').getImage();
$('#avatar').themestrapPluginImageUpload('destroy');
$('#avatar').themestrapPluginImageUpload({ endpoint: '/account/avatar', current: url });
