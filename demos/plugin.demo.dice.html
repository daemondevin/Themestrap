A tray of dice drawn with pure CSS pips. Throw some or all of them with a tumbling animation, let players pick dice by click or keyboard, and set dice aside. No images and no vendor dependencies.

01

Basic Tray

data-plugin-dice · roll()

Five dice with starting faces. roll() throws every die that is not held and returns a Promise that resolves with all values once they land.

Press Roll to throw the dice.


<div id="tray" data-plugin-dice
     data-plugin-options='{"count": 5, "values": [1, 2, 3, 4, 5]}'></div>

<script>
$('#tray').data('__pluginDice').roll().then(function (values) {
    console.log(values);   // [6, 2, 2, 5, 1]
});
</script>

02

Pick and Hold

selectable · hold · getSelected

With selectable on, click dice or use the keyboard: ← → move, Space picks. Set the picked dice aside with hold() and throw the rest, the way a Farkle turn works.

Throw, then pick dice to keep.


const dice = $('#tray').themestrapPluginDice({ count: 6, selectable: true })[0];

document.getElementById('tray').addEventListener('ts.dice.select', function (e) {
    console.log(e.detail.selection, e.detail.values);   // [0, 3]  [1, 5]
});

// Keep the picked dice, then throw the others
dice.hold(dice.getSelected());
dice.roll();

Fixed Results

roll(indexes, values) · setState

When a server decides the throw, pass the result in: roll([0, 1], [6, 6]) tumbles those dice and lands them on the given faces. setState() applies faces and held flags in one call without animation.


const dice = $('#tray').data('__pluginDice');

socket.on('rolled', function (msg) {
    dice.roll(msg.indexes, msg.values);   // the animation shows the server's result
});

dice.setState([{ value: 5, held: true }, { value: 1 }, { value: null }]);

Sizes and Faces

size · redOne · emptyFace

Three sizes, or any size with --ts-dice-size. redOne: false draws the one like every other face. emptyFace: "index" shows faces one to six on dice that have not been thrown, handy for a start screen.

size: "sm", redOne: false

size: "lg", emptyFace: "index"


<div data-plugin-dice data-plugin-options='{"size": "sm", "redOne": false}'></div>
<div data-plugin-dice data-plugin-options='{"size": "lg", "count": 3, "emptyFace": "index"}'></div>
