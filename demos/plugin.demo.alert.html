Themestrap · Plugin

Alert data-plugin-alert

A Bootstrap-compatible alert component with typed skins, optional icons, actions, dismiss controls, auto-dismiss countdowns, hover pause, animations, lifecycle callbacks, and a programmatic toast factory.


Static Alerts
Alert Types & Bootstrap Class Detection type auto-detection
This is an informational alert. Its type is detected from .alert-info.
Your changes were saved successfully.
Your session is about to expire.
The requested operation could not be completed.
This neutral alert explicitly supplies type: "neutral". 
$('#alert-info').themestrapPluginAlert({
  showIcon: true,
  dismissible: true,
  title: 'Information'
});

$('#alert-neutral').themestrapPluginAlert({
  type: 'neutral',
  showIcon: true,
  dismissible: true
});
Bootstrap alert classes can determine the plugin type automatically when type is null.
Titles, Icons & Dismiss Controls showIcon · title · dismissible
A more detailed message can be supplied directly by the original HTML. 
$('#alert-featured').themestrapPluginAlert({
  showIcon: true,
  dismissible: true,
  title: 'New software update',
  type: 'primary'
});
The plugin restructures the existing alert markup and adds its own icon, title, body, and close control.
Actions & Callbacks
Action Buttons primary · secondary · link
You have unsaved changes. Choose what you would like to do.

Last action

No action clicked yet.
$('#alert-actions').themestrapPluginAlert({
  showIcon: true,
  dismissible: true,
  title: 'Unsaved changes',
  actions: [
    { label: 'Save',    key: 'save',    variant: 'primary' },
    { label: 'Discard', key: 'discard', variant: 'secondary' },
    { label: 'Review',  key: 'review',  variant: 'link' }
  ],
  onAction(key) {
    console.log('Action:', key);
  }
});
Action buttons expose their configured key through the onAction callback and action.alert event.
Automatic Dismissal
Countdown & Hover Pause autoDismiss · delay · pauseOnHover
This alert automatically disappears after 8 seconds. Hover over it to pause the timer. 
$('#alert-countdown').themestrapPluginAlert({
  showIcon: true,
  dismissible: true,
  autoDismiss: true,
  delay: 8000,
  pauseOnHover: true,
  showCountdown: true
});
The bottom progress bar follows the timer and is recalculated when the alert is hovered.
Animation
Fade vs. Slide Dismissal animation 
$('#my-alert').themestrapPluginAlert({
  animation: 'fade',   // or 'slide'
  animationDuration: 400,
  dismissible: true
});
slide animates height, opacity, margins, and padding; fade only fades the alert.
Programmatic Toasts
Toast Factory PluginAlert.create() 
themestrap.PluginAlert.create({
  type: 'success',
  title: 'Changes saved',
  message: 'Your profile has been updated successfully.',
  showIcon: true,
  dismissible: true,
  autoDismiss: true,
  delay: 5000
});
With no container supplied, PluginAlert.create() creates a shared .alert-toast-stack on <body>.
Custom Containers
Injecting Alerts into a Container create(container, options)
Custom alert container 
themestrap.PluginAlert.create('#custom-container', {
  type: 'success',
  title: 'Saved',
  message: 'The alert was injected into this container.',
  showIcon: true,
  dismissible: true
});
Supplying a selector makes the plugin append the alert there instead of using the shared toast stack.
Lifecycle & API
Instance API & Lifecycle dismiss · destroy · data()
This alert can be controlled through the plugin instance.

Lifecycle log

const alert = $('#api-alert').data('__pluginAlert');

alert.dismiss();
alert.destroy();

$('#api-alert').themestrapPluginAlert({

Every initialized alert stores its instance under __pluginAlert and exposes dismiss() and destroy().
