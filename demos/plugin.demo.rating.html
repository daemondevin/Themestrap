PluginRating — Live Demo

Flexible star (or any-icon) rating widget with partial-fill display, custom icons via Font Awesome class strings or inline SVG, five sizes, clearable logic, and a full programmatic API. Zero build step, zero vendor dependencies beyond jQuery.

Every rating widget below is a live PluginRating instance. Instances are retrieved via $el.data('__rating') — the jQuery bridge does not support string method dispatch.

JS init · onRate callback · clearable

Basic interactive rating

The default configuration gives you a five-star, click-to-rate widget. Click the currently active star again to clear — this is clearable: 'auto' behaviour when maxRating is 1; for five-star widgets you need clearable: true explicitly.

No rating yet — click a star.

// Minimal init — all defaults applied
$('#r-basic').themestrapPluginRating({
    clearable: true,
    onRate: function(rating) {
        const msg = rating === 0
            ? 'Cleared — pick a star.'
            : `You rated ${rating} out of 5`;
        $('#r-basic-fb').text(msg);
    }
});

interactive: false · initialRating · partial fill

Read-only display ratings

Set interactive: false for display-only widgets. Fractional initialRating values (e.g. 3.7) render a partially filled star using a CSS linear-gradient clipped to the glyph via background-clip: text and the --full variable the plugin injects.

5.0 Perfect score · 2,841 reviews
4.3 Excellent · 1,204 reviews
3.7 Good · 587 reviews
2.2 Below average · 93 reviews 
// Read-only — fractional initialRating renders partial star
$('#r-ro-37').themestrapPluginRating({
    interactive:   false,
    initialRating: 3.7
});

Five sizes

Size is detected from a rating-{size} class on the wrapper element. The plugin appends the matching fa-{size} class to each Font Awesome icon. The wrapper's font-size provides an additional visual anchor.

icon option · any FA class string

Custom icons

The icon option accepts any Font Awesome class string or an inline SVG string. Colour theming is handled entirely through CSS custom properties on the wrapper — set --ts-rating-filled and --ts-rating-hover to match your palette.

fa-solid fa-heart · red
fa-solid fa-thumbs-up · blue
fa-solid fa-bolt · purple
fa-solid fa-circle · teal
Inline SVG diamond · currentColor: true 
// FA class string — any valid FA icon
$('#r-hearts').themestrapPluginRating({
    icon: 'fa-solid fa-heart',
    initialRating: 3
});

// Inline SVG — set currentColor:true to normalize fill/stroke
$('#r-inline-svg').themestrapPluginRating({
    icon: '<svg viewBox="0 0 24 24" width="1em" height="1em">...</svg>',
    currentColor: true,
    initialRating: 4
});

maxRating · 3-point / 10-point scales

Extended & compact scales

maxRating is not limited to five. A three-point scale works well for quick sentiment captures; a ten-point scale matches the NPS-style numeric range some audiences expect.

// 3-point scale
$('#r-three').themestrapPluginRating({
    maxRating: 3,
    onRate: (r) => $('#r-three-fb').text(r + ' / 3')
});

// 10-point scale
$('#r-ten').themestrapPluginRating({
    maxRating: 10,
    initialRating: 7,
    onRate: (r) => $('#r-ten-fb').text(r + ' / 10')
});

clearable · true / false / 'auto'

Clearable behaviour

clearable: true lets users click the active star to reset to zero. clearable: false locks the first choice in permanently. clearable: 'auto' (the default) only enables clearing when maxRating is 1 — a binary on/off toggle.

clearable: true — click the active star to reset

Not rated

clearable: false — first click locks permanently

Not rated

clearable: 'auto' with maxRating: 1 — like a favourite toggle

Not favourited

// Favourite toggle — auto clearable applies when maxRating is 1
$('#r-clr-auto').themestrapPluginRating({
    icon:      'fa-solid fa-heart',
    maxRating: 1,
    clearable: 'auto',
    onRate: (r) => $('#r-clr-auto-fb').text(r ? 'Favourited!' : 'Not favourited')
});

onRate callback · dynamic label

Descriptive labels

Use onRate to map the numeric value to human-readable copy — a common pattern for survey-style widgets where the numeric rating needs narrative context. 

const labels = ['', 'Terrible', 'Poor', 'Okay', 'Good', 'Excellent!'];
const subs   = ['', 'Really not happy', 'Room for improvement',
                'Could be better', 'Happy with this', 'Absolutely loved it'];

$('#r-label').themestrapPluginRating({
    clearable: true,
    onRate: function(r) {
        $('#r-label-text').text(labels[r] || 'Pick a rating');
        $('#r-label-sub').text(subs[r] || '');
    }
});

Public API · setRating / getRating / clearRating / enable / disable / destroy

Programmatic control

Every instance exposes the full public API. Retrieve the instance with $el.data('__rating') — the jQuery bridge returns the instance when the element is already initialized, but does not accept string method names.

State: active
Method log
No API calls yet — use the buttons. 
// Always retrieve instance before calling methods
const inst = $('#r-api').data('__rating');

inst.setRating(3);        // set value (fires onRate)
inst.setRating(3, true);   // set silently (skips onRate)
inst.getRating();          // returns current integer value
inst.clearRating();        // equivalent to setRating(0)
inst.disable();           // adds .disabled, unbinds events
inst.enable();            // removes .disabled, rebinds events
inst.destroy();           // full teardown — removes __rating data
