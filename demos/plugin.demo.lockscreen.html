PluginLockscreen

Full-viewport PIN lockscreen overlay with blurred backdrop, live clock, avatar, attempt limiting, idle auto-lock, and a clean unlock animation. Built on PluginOtp — both files must be included.

Default PIN for all demos on this page is 1234. Attempt limiting is set to 5 tries — after that the lock blocks for 30 seconds.

Basic Lockscreen

PIN: 1234 4 digits maxAttempts: 5

Click Lock Screen to activate the overlay. Enter PIN 1234 to unlock.

Events will appear here…
$('#lock1').themestrapPluginLockscreen({
    pin:         '1234',
    name:        'Alex Kim',
    message:     'Enter PIN to continue',
    maxAttempts: 5,
});

$('#lock1').on('ts.lockscreen.unlocked', function (e) {
    console.log('Unlocked with:', e.detail.enteredPin);
});

Idle Auto-Lock

idleTimeout: 20s showIdleBadge: true PIN: 1234

Click Start. Stop moving the mouse for 20 seconds and the screen will lock automatically. A countdown badge appears in the bottom-right corner when 30 seconds remain.

Events will appear here…
$('#lock2').themestrapPluginLockscreen({
    pin:          '1234',
    name:         'Robin Clarke',
    idleTimeout:  20,   // seconds of inactivity
    showIdleBadge: true,
    lockOnLoad:   false,
});

Runtime PIN Change

Change the expected PIN before locking

Set a custom 4-digit PIN, then lock. Enter it to unlock.

Events will appear here…
const ls = $('#lock3').themestrapPluginLockscreen({
    pin: '0000',
}).data('__pluginLockscreen');

$('#setBtn').on('click', function () {
    const newPin = $('#pin-input').val().trim();
    ls.setPin(newPin).lock();
});

Configuration Options

OptionTypeDefaultDescription
pinstring'0000'Expected PIN. Compared as plain strings. Change at runtime via setPin().
pinLengthnumber4Number of OTP boxes rendered.
pinTypestring'numeric''numeric' or 'alphanumeric'. Passed to PluginOtp.
namestring''User display name shown under avatar. Initials used if no avatar image.
avatarstring''URL to avatar image. Falls back to first letter of name.
messagestring'Enter your PIN to continue'Body message shown below the name.
use24hboolfalse24-hour clock format.
maxAttemptsnumber5Failed attempts before entering blocked state. 0 = unlimited.
blockDurationnumber30000Milliseconds to stay blocked after max attempts. 0 = permanent until reload.
idleTimeoutnumber0Seconds of inactivity before auto-lock. 0 = disabled.
showIdleBadgebooltrueShow a countdown pill in the corner when the idle timer is active.
lockOnLoadboolfalseLock immediately when the plugin initializes.
otpSizestring''Size passed to PluginOtp. '', 'sm', or 'lg'.
showClearbooltrueShow the Clear button below the OTP input.
submitLabelstring'Unlock'Label on the primary action button.
wrongPinMessagestring'Incorrect PIN. Try again.'Error shown on failed attempt.

Events

ts.lockscreen.locked

Fired when the lockscreen becomes active. No detail payload.

ts.lockscreen.unlocked

Fired on successful verification. detail: { enteredPin }

ts.lockscreen.failed

Fired on each wrong attempt. detail: { enteredPin, attempts }

ts.lockscreen.blocked

Fired when maxAttempts is reached. detail: { attempts }
