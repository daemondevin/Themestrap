Toast plugin

Auto-dismissing notification toasts — static API, nine positions, progress bar, icon variants, persistent mode

Types Positions Builder Static API
01

Types — success · danger · warning · info · default

type option

Click each button to fire that toast type. Toasts stack in top-right by default.

$('body').themestrapPluginToast({
  type:    'success',    // success | danger | warning | info | default
  title:   'Changes saved',
  message: 'Your profile has been updated.',
  delay:   4000,           // ms before auto-dismiss
  progress: true,        // show countdown bar
});
// click a type button above
02

Positions — nine placement options

position option

Select a corner/edge, then fire a toast there.

$('body').themestrapPluginToast({
  position: 'bottom-right',
  // top-left | top-center | top-right
  // middle-left | middle-center | middle-right
  // bottom-left | bottom-center | bottom-right
});
// select a position then fire
03

Builder — assemble a custom toast

all options in one go 
$('body').themestrapPluginToast({
  type:      'success',
  title:     'Build complete',
  message:   'assets/main.js rebuilt in 42 ms',
  delay:     5000,
  progress:  true,
  closeBtn:  true,
  position:  'top-right',
});
// configure above then fire
04

Static API — themestrap.PluginToast.show()

no jQuery element needed

The static helper fires a toast without needing a pre-existing DOM element — useful in fetch callbacks, event handlers, or anywhere without a natural jQuery context.

// call from anywhere — no element needed
themestrap.PluginToast.show({
  type:     'success',
  title:    'Saved',
  message:  'Record committed to the database.',
  delay:    4000,
  progress: true,
  position: 'bottom-right',
});

// delay: 0 → persistent, requires manual close
themestrap.PluginToast.show({ type: 'info', delay: 0, message: 'Action needed' });
// click a button above
