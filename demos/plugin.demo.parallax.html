Live examples of every parallax mode: classic background scroll, scale zoom, scroll-scrubbed CSS properties, and mouse pointer parallax — all zero-dependency.


Background Parallax default mode

Background Parallax

Image shifts slower than page scroll

<section data-plugin-parallax
         data-image-src="img/bg.jpg"
         data-plugin-options='{"speed":1.5,"parallaxHeight":"220%"}'>
  <div class="container py-5">Foreground content</div>
</section>
Scroll the page to see the parallax layer move.

bottom

     data-plugin-options='{"parallaxDirection":"top"}'>...</div>

Scale Zoom parallaxScale

Scale Parallax

Image zooms as you scroll

<section data-plugin-parallax
         data-image-src="img/bg.jpg"
         data-plugin-options='{"parallaxScale":true}'>
  <div class="container py-5">Content</div>
</section>
Scroll down — the image zooms in progressively.
Scale Inverted parallaxScaleInvert

Inverted Scale

Image starts large and shrinks

<section data-plugin-parallax
         data-image-src="img/bg.jpg"
         data-plugin-options='{"parallaxScale":true,"parallaxScaleInvert":true}'>
  ...
</section>
The image begins zoomed in and scales down as you scroll through.
Scroll-Scrubbed CSS Property scrollableParallax

Scroll down with this element in view to watch the bar grow:

20%

The width CSS property is scrubbed from 20% → 100% as the element passes through the viewport.

<div data-plugin-parallax
     data-plugin-options='{
       "scrollableParallax": true,
       "cssProperty": "width",
       "cssValueStart": 20,
       "cssValueEnd": 100,
       "cssValueUnit": "%"
     }'>
  <div class="scrollable-parallax-wrapper">...</div>
</div>
Scroll the page — watch the bar width grow.
