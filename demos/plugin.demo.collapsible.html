Collapsible plugin

Single-panel disclosure with animated height transition — the standalone counterpart to Accordion

Default closed Start open Custom easing API Events
01

Default — closed on init

defaultOpen: false

These are the advanced options that are hidden until the user needs them. The collapsible plugin measures the natural height of this element and animates the shell from 0 px to that value, then clears the inline style so the content can grow freely.

Using data-collapsible-trigger on the button and data-collapsible-content on the body is the standard markup convention.

<div id="my-panel">
  <button data-collapsible-trigger>Toggle</button>
  <div data-collapsible-content>…</div>
</div>

$('#my-panel').themestrapPluginCollapsible();
// defaultOpen: false (default)
// click the button above

04

Programmatic API

open · close · toggle · isOpen · setDisabled · destroy

This panel is controlled entirely by the buttons below. Clicking the trigger above also works — the API and the trigger share the same internal state machine.

const inst = $('#c-04').data('__pluginCollapsible');

inst.open();          // expand with animation
inst.close();         // collapse with animation
inst.toggle();        // flip current state
inst.isOpen();        // → true | false
inst.setDisabled(true); // make trigger inert
inst.destroy();       // unwrap shell, restore DOM
// click a button above
05

Events — open · opened · close · closed · change

Four events — open, opened, close, closed — plus the change event that fires on every toggle with the new boolean state.

$('#c-05')
  .on('open.ts.collapsible',   () => log('open'))
  .on('opened.ts.collapsible', () => log('opened — animation done'))
  .on('close.ts.collapsible',  () => log('close'))
  .on('closed.ts.collapsible', () => log('closed — animation done'))
  .on('change.ts.collapsible', (e, isOpen) => log('change: isOpen=' + isOpen));
// toggle the panel above
