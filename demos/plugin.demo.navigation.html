PluginNavigation — Live Demo

One plugin, three modes. mode:"sidebar" gives a collapsible icon-rail app drawer; mode:"panel" gives a vertical nav panel with depth-indented drawers; mode:"megamenu" gives a hover-/click-triggered mega-menu with full keyboard navigation. All from a single unified data-attribute namespace and one file.

Collapsible App Sidebar

Full header/body/footer structure, group labels, badge counts, animated sub-drawers, CSS tooltip in collapsed state. Click the chevron or use the API buttons to collapse/expand. Event log records every interaction.

megamenu mode:"megamenu" · hover + click · horizontal + vertical

Mega-Menu — Site Header Navigation

Hover (200 ms debounce) opens panels; moving the cursor into the panel before the close timer fires keeps it open. Arrow keys ←→ move between triggers, ↓ dives into the active panel, Esc closes and returns focus.
