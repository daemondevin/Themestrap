Themestrap Plugin

Random Images

A lightweight image rotation plugin with random selection, sequential playback, custom animations, per-image timing, stopping conditions, and a dependency-free wrapper slideshow.

Wrapper Mode

Images that stay loaded.

The wrapper implementation keeps every image in the DOM and simply transitions between them. No repeated src swapping.

Two ways to rotate

A single image can pull from an external image list, while wrapper mode can work directly with a collection of existing images.

Random selection

A new image is selected randomly while avoiding an immediate repeat.

random: true delay: 2500

Sequential selection

Images are presented in a predictable sequence rather than randomly.

random: false delay: 2500

Per-image animation

Wrapper images can define their own entrance and exit animations using data attributes.

Each image controls its own transition.

Per-image timing

Individual images can specify how long their transition should take with data-rimage-delay. 

<img
    src="image.jpg"
    data-rimage-delay="3000"
>

Automatic stopping

Random Images can stop automatically after a specific number of rotations or when a particular image index is reached.

Three rotations

Automatically stops after three changes. 

stopAfterXTimes: 3

Stop at index 2

Automatically stops when image index 2 is displayed. 

stopAtImageIndex: 2

JavaScript API

The plugin exposes a small dependency-free API for controlling individual instances. 

const instance =
    themestrap.PluginRandomImages.init(
        element,
        options
    );

instance.start();
instance.stop();
instance.destroy();

const existing =
    themestrap.PluginRandomImages.getInstance(
        element
    );

themestrap.PluginRandomImages.initAll(
    '.plugin-random-images'
);
