PluginTooltip — Live Demo

Lightweight, accessible tooltips with CSS-variable theming, four-side auto-flip positioning, eleven color variants, HTML content support, and full keyboard + touch support. Zero build step, zero vendor dependencies.

Every tooltip below is a live PluginTooltip instance running in your browser. Hover (or focus) any trigger to see it in action.

Minimal markup · attribute value as content

Basic tooltip

The simplest form: add data-plugin-tooltip to any element and set its value to the tooltip text. The plugin handles ARIA, positioning, and keyboard focus automatically.

Help 
<!-- The attribute value is used as tooltip content -->
<button data-plugin-tooltip="Save your work before continuing.">
  Save
</button>

location option · top / bottom / left / right · auto-flip

Four-side positioning

Set location in data-plugin-options to control which side the tooltip appears on. When there isn't enough room the plugin automatically flips to the opposite side — no extra configuration needed. 

<button data-plugin-tooltip="Tooltip to the left"
        data-plugin-options='{"location":"left"}'>
  Left
</button>

type option · 11 color variants

Color variants

The type option sets the color scheme via CSS custom properties. All colors are fully overridable with --ts-tt-bg and --ts-tt-color. 

<button data-plugin-tooltip="Action completed"
        data-plugin-options='{"type":"success","location":"top"}'>
  Success
</button>

html: true · rich content via options.content

HTML content

When html: true is set, the content option is injected as HTML. Sanitize any user-supplied content server-side before passing it to the plugin. 

<button
  data-plugin-tooltip=""
  data-plugin-options='{"html":true,
    "content":"<strong>Bold</strong> tip",
    "type":"dark",
    "location":"right"}'>
  Hover me
</button>

arrow: false · maxWidth · offset

Arrow, width & offset

Disable the arrow for a floating-label look, increase maxWidth for longer descriptions, or use offset to control the gap between the tooltip and its trigger. 

<!-- No arrow -->
data-plugin-options='{"arrow":false}'

<!-- Custom max-width -->
data-plugin-options='{"maxWidth":340}'

<!-- Custom offset gap -->
data-plugin-options='{"offset":24}'

delay option · [showMs, hideMs]

Show & hide delay

delay accepts [showMs, hideMs] or a single number that applies to both. Useful for preventing flicker on fast cursor passes, or for keeping the tooltip visible briefly after the cursor leaves. 

<!-- [showMs, hideMs] -->
data-plugin-options='{"delay":[500, 0]}'

<!-- Single number applies to both -->
data-plugin-options='{"delay": 0}'

Inline contextual help · non-button triggers

Inline text tooltips

Any element can be a tooltip trigger — not just buttons. Wrapping a term in a <span> or <abbr> with a dashed underline is a familiar pattern for in-context glossary definitions.

The Themestrap component library uses a triple-paren IIFE pattern for every plugin. Each plugin stores its instance at $el.data('__pluginName') and fires native CustomEvents rather than jQuery events for lifecycle hooks. 

<span
  data-plugin-tooltip="Tooltip text here"
  data-plugin-options='{"type":"dark","location":"top"}'>
  technical term
</span>

Public API · setContent(text)

Live content update

instance.setContent() replaces the tooltip text at runtime without destroying and re-creating the element. Useful for dynamic data like copy-link feedback.

Click the button to see setContent() swap the tooltip text in place. 

// Get the instance, then call setContent() at any time
const inst = $('#copy-btn').data('__pluginTooltip');
inst.setContent('Link copied!');

Public API · show() / hide() / toggle() / update() / destroy()

Programmatic control

Every instance exposes show(), hide(), toggle(), update(), and destroy(). After destroy, re-initialising brings it back with fresh options.

State: closed 
const inst = $('#my-tooltip').data('__pluginTooltip');
inst.show();
inst.hide();
inst.toggle();
inst.update();    // reposition after layout changes
inst.destroy();  // full teardown
